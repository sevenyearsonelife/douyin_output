## 一、总判断：AI 处于"公元前一年"

- 刘小排的核心命题：**"未来已经来了，但分布太不均匀"**——他称当下为 AI 的"公元前一年"，当超过一半人看到他看到的东西时，世界会发生巨变。
- 论据（口述数据）：ChatGPT 月活约 9 亿，但用 Codex（AI 编程）的只有约 500 万；80 亿人无法体会这 500 万人的感受，且 Codex 月费 200 美元，很多高薪大厂员工舍不得自购，只能从自媒体的炒作与贬低中形成认知。
- 主流与真理常不重合："一加一等于二"人人同意所以没有价值；**与主流完全不同而你知道是真的判断，才有价值**（他自称正尝试三五个人做出几十人公司的产品）。
- 上车不晚论：驳斥"股票"比喻——炒股可能亏，"上 AI 不太可能亏"；类比汽车普及率 3% 时买车、电力革命时用电。以荷塘睡莲每日翻倍作比：**"AI 今天进入的就是那个倒数第三天的样子"**，指数曲线前夜肉眼看不出。

## 二、两个激励案例（受访者转述，未核实）

1. **Ploy**：Webflow（约 900 人、承载全球约 1% 网站的建站公司）CTO 离职单干，口述称其 40 岁、疑似华人（字幕作"布莱恩·周/Brian Zhou"），一人烧掉约 75 万美元 token 做出比 Webflow 更强的产品——网站自带"主动性"：主动汇报访客行为、建议发邮件、自查搜索排名并提议修改，相当于"网站+运营+数据分析师"。
2. **Fable 5 与 GPT 5.6 被禁**（口述）：模型内测时能力过强，Anthropic 据称成立"玻璃之翼"项目请十几二十家公司测试，所有参与者都要求暂缓发布；据称其一击找出 Firefox 生产版 270 多个历史未发现漏洞，故被封禁。刘小排称自己用过 Fable 5 三天、几乎没睡，停用后看 GPT 5.5"觉得蠢爆了"。
   - 由此引出：强大编程能力已超过任何人类程序员，"找一百个五万美元的程序员不如用这个模型"（口述观点）。

## 三、AI 使用方法论的年度演进（2025.7 → 2026.7）

- **去年：教 AI**——把它当不行的工具，写细致指令、依赖现成 skill（模板）。
- **今年：减少自己的参与**——前提是**"让 AI 看到的世界无限趋近于你看到的世界"**：
  - 写 PPT 不再用 skill，而是像对待下属：讲 15 分钟思路 → 让它复述 → 认可提纲 → 离开，一天后产出；产出"每一句话都是我以前讲过的"，因此仍是自己的观点而非 AI 的观点。
  - 主持人补充：这更像"多年朋友/伴侣"、钢铁侠的贾维斯，因为共享全部上下文。
- **个人语料库三步法**：
  1. 历史资料一股脑给 AI（飞书七年记录、妙记、文章、演讲、录音），做版本管理；
  2. 日常线上数据通过 API 持续接入（微信、飞书、Twitter 点赞等）；
  3. 线下数据（录音、视频、照片）想办法喂给它。
  - 技术细节：尽量给原文而非压缩后的"金句"（**每次压缩都失真**），可用 embedding/向量数据库/RAG 检索。
- **skill 的定位**：适合新手补充上下文不足；上下文已对齐的人不需要。

## 四、"让 AI 泼你冷水"：对抗性用法

- 原理：模型经过人类偏好对齐（RLHF）后**倾向于顺着人说**——这是"豆包这么蠢的原因"（口述）。真正调出智能的方式是逼它唱反调。
- 实操 prompt 示例（口述）：
  - 代码："给我来一次**极不友好的 code review**，你对我有偏见"；
  - 商业：扮演"刚投资我竞品、女朋友被我抢了的投资人"，提哪些问题决定不投我；
  - 需求澄清："像苏格拉底一样问我，我的需求到底是什么"。
- **主持人的补充反思**（本段为主持人经验）：让 Opus 4.8 反复对抗性审查会陷入无限挑错、方案无法产出、决策瘫痪；他改为**"连续互动三轮以上即停止细节讨论、进入行动"**，并观察到"挑错也可以是一种讨好"。
- 刘小排的修正：若上下文未对齐（如不告知日活、并发、服务器规格），AI 只能给出泛泛"最优"方案——**"只有合适的，没有最好的"**。

## 五、效率（Productivity）vs 能力（Capability）

- 2023 年流行让员工汇报"AI 提效百分之多少"；2026 年提效 800% 只是基操，**该追求的是能力**。
- 两种心智模型：认为"AI 给我提效 20% 说明我厉害"的人，本质上仍以自己为中心；capability 心智是**承认一百件事里九十九件 AI 比自己强，专注做好自己那一件**。
- 金句：**"你意识到你爱上一匹野马，你要给他一个草原"，这才叫会用 AI。**

## 六、Token Maxing：把 AI 当员工的真正含义

- 现象（口述）：2026 年 2 月起海外（亚马逊、微软、Uber 等）到国内（字节、腾讯，"听说每人每月批 2000 美元 token"）刮起 Token Maxing 风。
- 刘小排的判断：大公司推不下去是必然（"平庸的人不配用这么多 token"，口述原话），一线创业公司会坚持——**token 再贵也比人便宜**。
- 每月刷掉四个 200 美元账号的秘诀：**"当员工用"= 你不在电脑前时它也在工作**；多数人"踹一脚干一会儿"，token 消耗自然上不去。要不断追问"怎么让它在我离开后一直工作"。

## 七、Claude Code 与 Codex 的分工（口述经验）

| 角色 | 比喻 | 擅长（口述） |
|---|---|---|
| Claude Code (Opus 4.8) | "思路比较广的 CEO" | 模糊想法阶段的头脑风暴、讨论；前端网页、动效交互 |
| Codex (GPT 5.5) | "很严谨的 CTO" | PRD 形成后的开发；后端逻辑、纯函数 |

- **交叉互审技巧**：Codex 写完先不提交，让 Opus 审（会服气）；反之 Opus 写、GPT 5.5 审，会审出大量 bug，贴回 Opus 它也认——由此得出"GPT 5.5 代码写得更好"的结论（口述体验，非基准测试）。

## 八、个人经历与职业观（受访者自述）

- **幸运论 vs 选择论**：他反复归因运气（小学四年级学编程、被傅盛收购进入猎豹做出海工具、恰逢 AI 编程兴起——"OINAI"〔字幕原文，名称待核〕）；主持人反驳"每个节点决策质量高"，他坚持"过度谦虚也是骄傲"的反问。
- **拒绝"表演上班"**：卷工时、看竞品楼灯、周末摆拍发朋友圈都是表演；下班时间是自己的选择。主持人点破：他能把 Agent 用好，与做产品经理时"推动不同部门干活"（协调、组织、串联上下文）同构。
- **一万小时定律是骗人的**：吃饭睡觉都超一万小时但水平无进步——**让人进步的是一万次迭代**。要去迭代周期快的地方：真实世界、有反馈、能复盘、能做下一次决策。
- **给年轻人的建议**：要么拿 AI 创业，要么加入"愿意给你机会被真实世界打脸"的小创业公司。
- **世界奖励离生产近的人**：体制内在"分配"不在"生产"；软件因分发成本低，是离生产最近的生产方式之一（富豪榜多为软件从业者）。
- **"困境是选择"**：只能手搓代码、只能用公司内部 AI 等环境约束，在他看来都是当事人自己的选择（原话较粗俗，此处意译），"我并不同情他们"。

## 九、关于中文自媒体与流量（主持人与受访者共同观察）

- 主持人（写公众号近十年）自述：AI 已成"掉流量的词"，写 AI 产品广告**必须从骂 AI 开始**（"臭 AI 让打工人更累、电脑不能合、账号不报销……"铺垫够长读者才愿意点开）。
- 受访者呼应（视频开场及结尾重复）：**"少看中文自媒体，有真人出镜的除外。"**
