什么是 PyTorch？简单说，它是一个专门用来构建和训练神经网络的开源工具库。你写的不是传统程序里那种一步步执行的操作，而是在搭一张巨大的计算图，数据从输入层流进去，经过一层层变换，最后从输出层流出结果。PyTorch 帮你管理这张图，并且自动完成最麻烦的一步，也就是计算梯度。这个视频会讲清三件事：PyTorch 到底解决了什么问题？它最核心的机制张量和自动求导是怎么工作的？以及为什么它在研究和工业界都这么流行？要理解 PyTorch 为什么重要，得先看深度学习训练的本质。训练神经网络的核心动作是反复调整参数，让模型的预测结果越来越接近真实答案。每一次调整都需要知道一个关键信息，就是损失函数相对于每个参数的梯度。网络越深，参数越多，手工推导这些梯度几乎不可能。早期研究者只能自己写反向传播代码，又慢又容易出错。

PyTorch 把这件事自动化了，你只需要定义前向计算过程，反向的梯度传播由框架自动完成。这就把研究者的精力从算导数中解放出来，转向设计模型本身。T Y Torch 的核心数据结构叫张量，英文是 tensor，你可以把它理解成一个多维数组。一个普通的数字是零维张量，一列数字是一维张量，一张表格是二维张量，而一张彩色图片可以表示成三维张量，分别是高度、宽度和颜色通道。一段视频则是四维张量，多了一个时间维度。张量和普通数组最大的区别在于，它可以在显卡上做并行计算，并且会记录自己参与过的运算，为自动求导做准备。自动求导是 PyTorch 真正的心脏。当你创建一个张量并设置 requires 下划线 grad 为真时，PyTorch 会在后台悄悄构建一张计算图。

比如你写 c 等于 a 加 b，然后 d 等于 c 乘二，最后求 d 的平均值，这每一步操作都会作为节点记录在图中。当你调用 backward 方法时，PyTorch 从最终结果出发，沿着这张图反向遍历，用链式法则自动算出每个参数的梯度。这种动态构建计算图的方式，是 PyTorch 区别于早期框架最明显的地方。这里要解释一个关键概念，叫动态图。早期的一些框架采用静态图，你必须先把整个网络结构定义好，编译之后才能输入数据运行，这有点像写完整份剧本再开拍。PyTorch 则采用动态图，也叫即时执行模式，计算图是在你写代码的过程中实时生成的。你写一行加法，图里就多一个加法节点。这意味着你可以用普通的 Python 控制流，比如 if 语句和 for 循环，来随意改变网络结构。

对研究者来说，调试模型就像调试普通程序一样自然，可以随时打印中间结果，也可以根据输入数据的不同，走不同的计算分支。在实际使用中，用 PyTorch 搭建模型通常遵循一套清晰的流程。第一步是准备数据，把图片、文本或表格转换成张量，并分批送入模型。第二步是定义模型，通常继承一个叫 Module 的基类，在初始化函数里定义各层，在前向函数里描述数据如何从输入流向输出。第三步是选择优化器，比如常用的 Adam 或 S G D，它会根据梯度更新参数。第四步是写训练循环，反复执行前向计算、计算损失、反向传播和参数更新这四个动作。这套流程几乎适用于所有深度学习任务，从图像分类到语言模型。T Y Torch 之所以流行，还有一个重要原因是它的生态。

Torch Vision 提供图像数据集和预训练模型，Torch Audio 处理音频，Torch Text 处理文本。如果你想把模型部署到手机或服务器，有 Torch Script 和 ONNX 这样的工具把模型导出成标准格式。对于分布式训练，PyTorch 也提供了数据并行和模型并行的接口。这些工具让同一个框架既能做快速实验，也能走向生产环境。最后总结一下，PyTorch 是一个以张量为基础，以自动求导为核心，以动态计算图为特色的深度学习框架。它把神经网络训练中。最困难的反向传播自动化了，让研究者可以用接近普通编程的方式设计和调试模型。无论你是想入门深度学习，还是需要快速验证一个新想法，理解 PyTorch 的这些基本机制都是绕不开的第一步。
