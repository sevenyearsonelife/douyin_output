你有没有发现一个现象，就是很多新机会刚开始的时候没几个人关注，等到所有人都开始讨论的时候，机会可能已经发生了很大的变化。就像今天我们聊这个 Web 三，可能很多人还不知道 Web 三是什么，更不知道它和区块链、比特币它有什么关系。但我想说的是啊，一个新领域真正值得关注的时候，往往不是所有人都已经明白的时候，而是它刚刚开始发展，规则还在形成的时候。为什么这么说呢？因为当一个新的事物刚出现的时候，大多数人呢看不懂，有人觉得它是骗局，有人觉得它离自己的生活太远，还有人呢根本不愿意花时间去了解。但是随着技术的不断发展，应用也越来越多，关注的人呢也会慢慢的增加。等到大家都在讨论它的时候，整个行业可能已经发生了很大的变化。当然啊，这就不代表早期参与就一定能赚钱，也不代表所有的新技术最后都能成功。

小姨认为呢，普通人面对新事物，最重要的不是急着去投钱，而是先花时间搞明白 Web 三到底是什么，它想解决什么问题，它和我们今天使用互联网有什么区别，它未来可能在哪些领域产生影响。这些问题可能比单纯盯着某个币涨了多少更值得我们去研究。我做了这么多年的投资，现在就是看不懂的时候我不着急去否定它，听懂了的时候也不急着冲进去，先理解再判断，这才是普通人面对新机会应该有的态度。
