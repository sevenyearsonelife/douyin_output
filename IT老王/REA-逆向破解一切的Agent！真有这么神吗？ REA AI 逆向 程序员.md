最近大家一定刷到过一个叫 R E A 的项目吧，号称是让所有商业软件的天都要塌了，在 Git Hub 上飞速收获了两百多万的 Star，各种短视频更是吹得神乎其神。这玩意干什么的呢？正式点的说法是个程序逆向的 Agent，但说人话就是有了这 R E A 啊，以后不管什么收费软件，咱们普通人点几下鼠标就能自己搞个免费版出来。有朋友还特兴奋的跑过来问我啥感觉，是不是心里拔凉拔凉的，这下所有程序员下岗，你总没话说了吧？于是我赶紧一路小跑就玩了一下，发现这个饼画的有点大。这次我就来跟你分享一下这个 R E A 到底有多玄乎。我是楼兰，关注我，IT 路上一起进步。

不知道你有没有留意到一件事情，网上虽然到处都能看到有人用 R E A 逆向了这个逆向了那个，但是你真想找个手把手教你怎么去逆向剪映、逆向 Photoshop 的实操视频，根本找不到。其实啊，这还真的不是博主们不想抓这波流量，而是因为 R E A 这个东西一开始就撞上了一堵不可逾越的墙，法律。R E A 本质上它是个 M C P 服务，也就是说它不是自己单独跑的，它设计出来就是必须要搭在像 Code X、Cloud Code、Worker Buddy 这样的 Agent 工具上面才能跑的。但市面上的这些主流 Agent 底层设定就必须受法律限制，而法律是明确规定了逆向破解别人的闭源商业软件这事它是违法的，情节严重甚至还会留下刑事案底。

所以现在这些主流的 Agent 一旦看到你要逆向一个像 Photoshop 这样的商业软件，第一时间就会明确的拒绝。像我尝试了好几个 Agent 都是这样的，逆向一切的雄心壮志第一时间就被泼了一盆冷水。这法律就从根本上决定了逆向一切的宏伟蓝图它是不存在的，顶多你就逆向几个小工具自己玩玩。当然有朋友可能会说，既然主流的 Agent 受限制，那我自己手搓一个没有限制的 Agent 出来，再配合 R E A，这你管不到我了吧？再把我逆向出来的 Photoshop 随便换个名字，比如 Photo Factory，这不就万事大吉了吗？想法很好，但这里还有一个很大的误区，大家把逆向和做出一款软件等同了起来。其实逆向的本质只是帮你去抓包、分析数据，去理清楚原始软件的核心逻辑，但这仅仅是个基础。

做过开发的朋友肯定就深有体会，你自己随便写个简单的权限系统，里面的健全逻辑和业务逻辑经常都是死死混在一起的，你更别说像 Photoshop 这种顶级的商业软件了，那代码里的健全逻辑更是千丝万缕，甚至很多核心验证是直接跟云端绑定的。你通过逆向确实能看懂它大概是怎么运转的，但这不等于你就能把那些缝合到骨肉里的健全逻辑点点剥离开，然后再完美复刻出一个一模一样的不要收费的东西出来。有时候去剥离这些东西的难度真的不亚于你自己重新写一个软件。还有人会说，你别说的这么夸张，网上确实有人搞出了免费版的 Photoshop 啊，我自己搞不定，那我等着用别人的，这种行了吧？

行肯定是行，那接下来咱们从人性的角度简单想个问题，别说那些技术顶尖的黑客学了那么多年的技术了，就说是一个普通人，比如是你，你费了九牛二虎之力烧了一大堆的头，可终于把一个复杂的软件给复刻出来了，你会什么都不图免费发给网上给所有人随便用吗？大概率是不会的吧，免费的往往是最贵的，这个简单的逻辑放在哪里都适用。那些所谓的免费破解版，不管包装的多好，本质上它都是盗版软件，换上这个名字你是不是就熟悉多了？别告诉我你没有被盗版软件坑过啊，简单点的花了钱用不了，厉害点的给你塞点木马后门什么的，你电脑上那点稍微值钱点的资料全都给你薅的干干净净，有没有玩过传奇的朋友出来说道说道的。说到这里大家可能觉得，那照你这么说这个 R E A 岂不是一点用都没有，全是噱头了？

其实也不是，逆向这个技术它就是个双刃剑，跟爬虫一样，如果心术不正，那就很容易走灰产的路子，所以它天生是不适合普通人的。但如果我们换一个思路，不要老是去盯着白嫖收费软件那个点，你会发现 R E A 这个项目确实是把逆向的技术门槛降低了很多，像你我这样完全不懂逆向的小白也能用这个项目来体验体验逆向技术的魅力，而且本身这个项目就非常有意思，能给我们带来很多新的启发。首先对于 Agent 稍微有点好奇心的新手朋友，R E A 其实提供了一个非常棒的把传统技术和 Agent 结合的新思路。

R E A 本身并没有创造新的技术，但是它整合了很多常用的逆向技术和工具，从它的 Git Hub 仓库就能看到，它能自己解析 Java、Go、Rust、.NET 这些常见的开发语言，也能够分析 Electron、Circle Light 还有 APK 这样一些开源的技术框架，还能够连接像 Ghidra、IDA、Hopper 这些经典的逆向工具。最终 R E A 把它们整合成了一个 M C P 服务，结合大模型降低了应用门槛，同时也解决了不同逆向技术之间的适配性。这其实验证了一个很大的趋势，就是绝大部分现有的传统业务和老工具其实都可以用 M C P 去搭桥，结合 A I 去使用它们，这个思路我觉得比单纯破解个软件有意思的多。那既然不能去搞商业软件。但是呢，逆向到底是怎么玩的呢？

如果你是个有一定开发经验的程序员，我也建议你自己亲手去动手试试。这里呢，我用 Java 写了一个简单的应用程序啊，我们来玩一玩这个逆向。实际上这就是一个粒子爆炸效果这么一个小程序啊，以前专门喜欢写这种东西来活跃活跃脑子，那现在肯定也都交给 AI 了。那有了这个应用程序，我们就可以交给 R E A 去进行呃逆向了。R E A 呢它是一个 M C P 工具，所以需要装在一个 Agent 的呃工具上面，所以我这里就用了一个呃 Work Buddy 去装了一个 R E A 啊，然后直接就告诉它有这个工具，然后调调用 R E A 帮我逆向生成这个小程序源码，经过一通分析之后，它就能够快速的来进行反编译，最后生成相应的源码啊，源码的质量我对比了下还是挺高的。

然后呢可以看到它也生成了几个不同的版本呢，这里像 verified 表示是验证过的，还有呢像前面是像这个 decompiled C F R，这个就是用 C F R 原始反编译出来的，还经过了一些呃验证啊校对啊做一个补充。比较有意思的呢是它的一个执行过程啊，可以看到这么一个简单的加包呢，整个编译的过程其实也不短，那总共跑了有六分多钟的时间，那你如果用一些 J D G I 这样的工具去看的话，可能比这个要快很多。然后呢下面还有一个有意思的地方就是可以这里可以看到整个执行过程呢提了 R E A 干不了 J V 反编译，为什么这里也说了，那就是 R E A 实际上它需要调用一个外部的 J E B 客户端来进行逆向，这个 J E B 是什么呢？

J E B 实际上是一个商业化的一体的这个逆向的服务平台，它本身就是专门来逆向这些二进制的应用程序的，而且不光是就是不光是 Java 这种啊，包括我 Linux 上的应用程序啊，你操作系统上的这些应用程序，包括 Mac 电脑上应用程序全部可以交给这个 J E B 去进行逆向，而这个 J E B 呢实际上如果你做 Java 这个事儿它还是要收费的，所以这个门槛其实不低。这里也能看到就是 R E A 它本身实际上是把任务进行一个分发，它并不是说自己完成去完全做成逆向这个事儿，而是去调动别的一些工具去进行逆向，然后后面发现呢检查本地没有这个呃 J E B 的客户端之后，那接下来就会啊走另外一种思路，怎么走的？这里其实也提到了就是 R E A 它做不了这个事儿，那怎么办？

大模型自己来做，自己的做的方式就是通过 R E A 来打开这个二进制文件，就 class 文件，然后呢通过 Java T 指令去对这个 class 文件去看一下它的结构，接下来用 C F R 来进行反编译，C F R 就是一个专门来反编译 Java 的一个工具了，就它能够通过 class 文件生成对应的 Java 文件，然后呢整个模型还整个驱使它去呃完成整个校验的过程，就通过 C F R 反编译出这个 Java 程序之后，它也来进行一次正向的 Java 十一编译，又编译成 class 文件，把这个再次生成的 class 文件和目标的 class 文件进行一下对比啊进行一下校验啊，这样最终生成这种啊这个结果，所以这里这就是整个这个逆向的一个过程，可以看到这就是逆向在合法合规范围内的一个玩法，它其实是一门非常正统的技术，在实际的工作场景当中，逆向技术主要是用来分析恶意软件，排查安全漏洞或者研究不同软件之间怎么互通的，它是一门用来防御和研究的技术，而不是用来搞破坏的。

其实软件逆向这个东西和爬虫技术就很类似，就是易上手，但是要精通却很难，因为在这里道高一尺魔高一丈，但其实也意味着你永远不会觉得枯燥。实际上逆向从来不是一个新的东西，像我们这里其实早就有了很强大的逆向课程。有人说有了 R E A 商业软件就要变天了，但其实咱们回头看看，盗版破解版这几十年什么时候少过？我就不信你没用过几个绿色版本的 Photoshop。历史其实无数次告诉我们，就算你破解成功了一个商业软件，明天人家官方来个大更新，塞几个你眼馋的不行的新功能，你最后还不是要乖乖的升级版本。你手边的 Windows、Adobe 全家桶，还有程序员以前天天用的 I D E A 全家桶，哪个不是这样过来的？

只不过确实 R E A 的出现，在提醒我们这 A I 时代所有东西都发展太快了，你别说停下脚步了，这里前进动作稍微慢一点，那都是在倒车，所以搭上 A I 的风，跟上这个时代吧。
