Web Coding这个词大家最近应该没少听说吧？网上天天有人在说，这AI时代不再需要程序员，人人都能写代码，所以人人都是程序员。前两天我也好奇，就去BOSS直聘上搜了一下Web Coding，好家伙，那岗位比我想象的多得多啊。有了这玩意儿，开发软件就跟聊天一样，动动嘴皮子把需求描述清楚就行了。我当时还在想，这以后程序员怕不是要让文科生来干了吧？那咱们还学个毛的技术，大家都去学怎么写需求文档得了。但是当我点开这些岗位的要求一看，发现事情没那么简单。按你说AI把写代码的门槛踩的稀碎，对人的要求应该变低了才对吧？结果你看看，招聘要求上清一色的写着精通Java，精通Python，还要熟练掌握各种中间件，甚至还有很多要精通前端开发。这要求不但没降，反而还拔高了，这是不是有点奇怪？

AI都能一键生成代码了，企业为什么还要要求你精通这个精通那个呢？这不是自找麻烦吗？在AI自动写代码的今天，咱们到底还要不要去学技术？今天我就带大家来探探这个底。大家好，我是罗兰，关注我，IT路上一起进步。其实招聘市场出现这些反常现象，你细想一下背后的逻辑非常的现实。你看现在AI确实能够一下就写出一大堆的代码，但这些代码质量怎么样？会不会有隐藏的bug呢？能不能满足你现有项目的设计要求呢？说白了，企业对AI写出的东西心里其实还没那么放心。这就好比你手下招了一个名牌大学刚毕业的应届生，能力呢确实强，干活也确实快，但你就敢直接把核心业务交给他们？大概率是不敢的，你总得安排个经验丰富的老员工跟他结对编程，带他上上手，给他把把关吧。

AI也是一样的，至少在现阶段，企业还是非常需要那些能给AI兜底，能够帮忙排查底层bug，能够检验AI编程效果的技术能手。所以你会发现现在有了AI之后，有些朋友出去面试遇到的问题会越来越变态，动不动就要深挖架构设计还有项目实战呢。其实很多时候这些面试题的目的就不再是检测你写代码的能力了，而是要去检验你有没有带AI工作的能力。不知道大家最近面试有没有遇到过这种特别奇葩的面试题，可以在评论区分享一下，咱们一起避避坑。如果说招聘市场还只是老板们在卷，那咱们再看个更加宏观的现象，未来行业怎么样呢？那高校肯定看得比咱们更真实更远。最近互联网上非常流行一个话题，就是整理高校的裁撤专业名单，你应该也刷到过这样的短视频吧？

这次我从教育部的官网上给大家整理了一下过去几年双一流高校裁撤最多的前十名专业，像电子商务啊、公共事业管理、市场营销这些以前听起来门槛不高，像万金油一样的专业，现在砍的最狠。这名单里面有没有你的专业啊？原因其实很好理解，市场不景气嘛，需求减少了，学生毕业不好找工作，自然就影响到高校的招生了。但是你再仔细看看，跟咱们程序员最对口的计算机科学与技术专业，专硕在持续扩招，学硕甚至还在新增博士点。你可能会说这是国家在搞AI科技竞赛嘛，那咱们看看最直接面向市场的本科，计算机本科几乎是零裁撤。其实这就足以说明，在真实的就业市场上，硬核的技术人员根本就没有过剩，反而依然是极其稀缺的资源。说到这儿，我特别想在评论区做个小调查，如果现在让你重新填报一次高考的志愿，你会选择计算机专业吗？

在评论区看看大家的选择怎么样，那我给大家说一下，我是肯定会毫不犹豫的选择是的，甚至我想从高中就开始选，毕竟当年我身边很多同学高中就选择参加了信息竞赛，现在一个比一个牛，像我高中的班长后来进了微软，不过身体出了点问题已经去世了，这个我就不说了。当你把这两件事放到一起看，答案其实就已经摆在明面上了，程序员其实依然是个非常不错的职业选择，只不过现在的环境对程序员提出了完全不一样的要求。我总结下来核心是两点，第一点，专业面要求更广了，Java和Python以后基本不分家了，前后端全栈精通成了标配。为什么？因为AI帮你写代码的效率提上去了，技术语言不再是你的限制了。

虽然有人会说以后可能就根本就不需要Java Python了，AI都能够直接在操作系统层面去开发，但那毕竟是科幻小说里的事，至少在可预见的时间里，程序员作为AI的掌舵者是绝对必不可少的。第二点，思考能。已经远远大于动手能力了。以后很现实的一个情况是，你可以不会写代码，但你绝对不能不会看代码。你随便用个 AI 工具，轻轻松松就能写出好几行代码来。那接下来评判哪个方案更好更合适就越来越重要了。但这就跟评测哪个 AI 大模型更强一样，很难有绝对统一的标准。所以代码最终需要怎么去落地呢？这还是需要有人来拍板，来做取舍。那怎么取舍？其实靠的就是你的代码审美。而审美的背后其实就是你对问题的思考深度。你的经验越丰富，平时积累的越深，你才能做出让你的团队不得不相信的决定。

打个比方，你出去旅游问路，你是愿意去相信一个拿着手机跟你一样东张西望的小白呢，还是愿意相信一个闭着眼睛都知道哪条巷子能抄近路的本地人？那企业其实也是一样啊，这么专业的事，谁敢交给一个什么都不懂的小白呢？所以大家千万别被网上那些贩卖焦虑的言论带乱的节奏。Web Coding 是个大趋势，我们要做的就是好好去拥抱它。至于剩下的事，就是把心沉下来，把底层逻辑吃透了。当你真正把技术学到了自己脑子里面，把 AI 训成了你手里最听话的牛马，那你就可以成为企业最放不下的主心骨。至于具体怎么把 Web Coding 在实际开发中落地，我这边准备了大量 Java 加 AI 的一整套实战内容，后续会慢慢给大家分享。记得点赞、关注、收藏，我是罗兰，关注我，IT 路上一起进步。
