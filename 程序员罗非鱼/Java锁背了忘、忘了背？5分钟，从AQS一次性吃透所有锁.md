Java锁背了忘，忘了背。今天我们用五分钟从 A Q S 出发，一次性把 Java 里的锁彻底吃透。很多人学锁，今天看 Reentrant Lock，明天看 Semaphore，后天看 CountDownLatch，总觉得是好几套东西。其实它们背后只有一个核心，就是 A Q S。只要把 A Q S 想明白了，所有锁都是它的变体，你根本不需要背。那 A Q S 是什么？它的全称叫 Abstract Queued Synchronizer，翻译过来就是抽象队列同步器。你可以把它理解成一个底层的排队管理系统。当多个线程抢同一个资源时，总得有先来后到，A Q S 干的事就是管理这个先来后到。它内部维护了一个状态变量叫 state，还有一个等待队列。state 表示资源被占用的状态，队列里排着那些暂时抢不到资源的线程。

谁拿到了 state 谁就拥有锁，拿不到就去队列里排队等着。那为什么理解 A Q S 就能理解所有锁呢？因为 Java 里几乎所有重要的同步工具，底层都是基于 A Q S 实现的。比如 Reentrant Lock，也就是可重入锁，它把 state 当作重入次数，同一个线程每加一次锁，state 就加一，解锁时减一，减到零才真正释放。再比如 Semaphore 信号量，它把 state 当作剩余许可证的数量，线程拿许可证时 state 减一，用完归还时加一。CountDownLatch 呢，把 state 当作需要等待的事件数量，每完成一个事件就减一，减到零，所有等待的线程一起放行。你看，锁、信号量、门栓，表面各不相同，本质都是在操作 state 加上一套排队唤醒机制。

所以你只要搞懂 A Q S，就等于拿到了所有锁的通用说明书。那 A Q S 具体怎么工作？分三步，第一步抢锁。线程来了，尝试用 C A S 操作把 state 从零改成一。C A S 是 Compare and Swap，意思是先比较再交换，只有当前值等于预期值时才修改。这个操作是原子性的，底层由 C P U 保证。如果改成功了，锁就到手了。如果失败，说明锁被人占着，进入第二步排队。线程会包装成一个节点，放到 A Q S 的等待队列尾部，然后调用 Lock Support park，把自己挂起，进入等待状态，不占 C P U。第三步唤醒。当持有锁的线程释放锁，也就是把 state 改回零时，A Q S 会唤醒队列头部的下一个线程，让它重新尝试抢锁。整个过程就是抢不到就排队，释放了就通知下一个，公平又高效。

这里有个关键点，就是公平锁和非公平锁的区别。非公平锁是线程来了直接先抢一次，不管队列里有没有人等，抢不到才去排队。公平锁则是严格按队列顺序来，先排队的先拿锁。你可能会觉得公平锁更好，但实际中非公平锁性能往往更高，因为它减少了线程唤醒带来的上下文切换开销。所以 Reentrant Lock 默认是非公平的。这就像餐厅排队，非公平是来了先探头看看有没有空位，有就直接坐，没有才去队尾。公平是老老实实排着，非公平偶尔会让队头的人多等一会儿，但整体翻台率更高。还有一个必须理解的概念叫可重入，它指的是同一个线程可以重复获取同一把锁，不会把自己锁死。比如一个递归方法里反复加锁，如果是非可重入锁，第二次加锁就会发现自己被自己阻塞，直接死锁。

而 Reentrant Lock 借助 state 计数，同一个线程加一次就加一，释放一次就减一，所以可以放心嵌套。这个设计非常实用，因为代码里经常出现一个方法调用另一个方法，两个方法都加了锁的情况。那实际使用中怎么选锁？如果你的需求是互斥访问共享资源，选 Reentrant Lock。如果你需要限制同时访问的线程数量，比如数据库连接池，选 Semaphore。如果是一个线程等另外几个线程都完成后再继续，选 CountDownLatch。如果是线程之间互相等待，步调一致，选 Cyclic Barrier。还有读写。场景：读多写少，用 ReentrantReadReadLock，读锁可以共享，写锁独占，能大幅提升并发度。最后说一个容易踩的坑。

很多人用锁时习惯用 synchronized，它其实是 JVM 层面的内置锁，底层也有一套类似的升级机制，从偏向锁到轻量级锁再到重量级锁。而 AQS 是 Java 层面的实现，更灵活，能响应中断，支持超时，能做公平与非公平切换。但无论哪种锁，使用原则都一样：锁的力度要小，持有时间要短，释放一定要放在 finally 里，保证异常时也能解锁。否则一旦锁没释放，其他线程就会无限期等下去，系统性能直接崩掉。总结一下，你不需要背每一个锁的用法，你只需要记住 AQS 这一个模型，一个 state，一个等待队列，加上 CAS 和 LockSupport 的配合。ReentrantLock 是计数，Semaphore 是减许可证，CountDownLatch 是倒数门闩，它们全是在这个骨架上换皮。

理解了这一点，遇到再没见过的锁，你也能一眼看穿它的本质。
