像我们这种经常做行业研究的，就是要经常整理数据、搭框架、做 PPT，不难就是麻烦。今天老东做一个纯实操教程，教大家怎么使用豆包的 Agent 功能快速做出像这样子的分析报告和 PPT。这里点一下进到工作任务，也就是切换到了 Agent 模式了。首先是要做行业分析报告，这里我们就要用到最基础的文档技能。在技能这里选好，很简单，你想要调研什么行业就说什么。比如我想要分析的是今年上半年的能源行业分析报告，它自己就会去抓数据、创文档、分析趋势，最后给我们一个很专业的文档，基础框架搭的特别清楚，我们在这个基础上去修改就很轻松。当然汇报嘛，肯定需要有图表，可视化这个技能就是为了这种情况去准备的。点击选择之后，输入指令就能把统计报表里的数据转化为图表。如果你想把图表插入到文档对应的位置，说一下就能实现。

做完这一步，分析报告、图表我们都有了，那接下来就是要做汇报用的 PPT。最简单也是最方便的办法就是用内置的 PPT 技能，也是在技能里，我们找到之后点一下选上，简单说一下生成一份完整行业分析汇报 PPT，包含行业现状、机会分析、行业标杆、风险提示等几个模块。你看过一会儿就生成了一份 PPT，排版结构基本上就是拿过去直接就能汇报了。如果要改的话，在线编辑就可以。这些技能都是可以单独调用的，也可以组合串联在一起完成复杂的任务。还有个我觉得豆包很符合我们职场的情况，豆包完全打通了手机和电脑的同步，任务在电脑端跑的时候几乎没有延迟就同步到了手机端，而且还能通过云电脑用手机操控你的电脑，即便你的电脑在睡扁。所以哪怕你没带电脑，要查什么资料也完全能够用手机去查去修改。

简单总结，Agent 的核心就是帮你去完成工作，用简单的话拿到一个好的结果，但是要提醒一句，生成的东西都要人工二次核对调整。不管是财经人做行业分析，还是上班族做工作汇报，总体上老东还是很推荐大家的，有内容输出的地方都可以让 Agent 跑一遍试试看。
