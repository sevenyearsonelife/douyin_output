# 抖音作者文案归档库

归档抖音（财经/投资为主）创作者的**公开视频口播文案**，按主播分文件夹存放。每条视频一个 Markdown 文件，配套账号信息、视频索引与提取记录，便于后续检索、对比与观点总结。

- 收录账号：**37 个**（个人投资者、投教博主、基金公司机构号等，兼有少量科技/出海/剧评类账号）
- 归档文案：**约 2600 条**视频文案
- 生成方式：由 Claude Code 的 `douyin-pipeline` 管线自动提取（语音转写 + 画面文字复核），人工触发、增量写入

> 内容均为对公开视频的转写与整理，仅供学习研究，**不构成投资建议**；主播自述背景、持仓、收益均未经独立核实。

## 目录结构

```text
douyin_output/
├── README.md                                  # 本文件
├── 全主播投资理念总览.md                        # 跨主播理念汇总（入口文档）
├── 小姨与大志_投资理念与标的深度对比报告.md       # 双主播深度对比报告
├── .gitignore
└── <主播昵称>/                                 # 每个主播一个文件夹，共 37 个
    ├── account.json                           # 账号信息（昵称、sec_uid、主页链接）
    ├── video_urls.json                        # 已采集的视频链接清单
    ├── index.md                               # 视频索引表（序号 / 链接 / 标题 / 写入时间）
    ├── summary.json                           # 提取记录（状态、提取方式、复核状态等）
    ├── <视频标题>.md                           # 每条视频一个文案文件
    ├── _总结_*.md                              # 该主播的理念/风格总结（部分主播有）
    ├── transcripts/                           # 语音转写原始 JSON（中间产物）
    └── _review/                               # 抽帧复核图片与元数据（中间产物）
```

## 主播文件夹内文件说明

| 文件 | 作用 |
| --- | --- |
| `account.json` | 主播昵称、`sec_uid` 与主页链接，用于断点续跑与账号校验 |
| `video_urls.json` | 采集到的视频 URL 列表 |
| `index.md` | 全部视频的索引表，标题即指向对应文案文件的超链接，**检索入口** |
| `summary.json` | 每条视频的提取记录：`status`（提取状态）、`extraction_method`（如 `speech_recognition`）、`model`（转写模型）、`review_status` / `review_note`（复核结论）等 |
| `<视频标题>.md` | 视频口播文案正文。文件开头附**视频链接**与索引回链，正文为完整口播转写 |
| `_总结_*.md` | 基于实际文案归纳的主播投资理念与风格总结 |
| `transcripts/` | ASR 原始转写 JSON，按视频 ID 命名 |
| `_review/` | 配乐/无语音视频的抽帧 PNG 与 `frames.json`，用于画面文字（OCR）复核 |

## 根目录汇总文档

- [`全主播投资理念总览.md`](全主播投资理念总览.md)：汇总各主播的身份定位、理念内核与数据基础，附总目录表
- [`小姨与大志_投资理念与标的深度对比报告.md`](小姨与大志_投资理念与标的深度对比报告.md)：两位主播在理念与标的上的逐项对比

## 常用检索方式

1. **按主播浏览**：进入对应文件夹，打开 `index.md`，按标题点击跳转到文案
2. **按关键词检索**：在仓库内全文搜索（如 `grep -r "红利" */`），文案均为纯文本 Markdown
3. **核对提取质量**：查看该主播 `summary.json` 中的 `status`、`review_status` 与 `review_note` 字段

## 追加新内容

本仓库由 Claude Code 的 `douyin-pipeline` 管线维护，在 Claude Code 中以自然语言发起即可，例如：

```text
/douyin-pipeline 提取主播"XX"主页前 50 条视频文案
```

管线支持：昵称搜索与同名账号选择、主页分享短链、指定范围或前 N 条、断点续跑、语音转写、配乐视频画面文字复核、按作者归档。

## 忽略规则说明

`.gitignore` 已将以下中间产物排除在版本库之外（历史已跟踪的文件仍保留，用于追溯复核依据）：

- `transcripts/`：ASR 原始转写
- `_review/`：抽帧复核图片
- `*_review/`、`_profile_*/`、`_search/`、`_tmp/`：浏览器自动化临时目录与日志
