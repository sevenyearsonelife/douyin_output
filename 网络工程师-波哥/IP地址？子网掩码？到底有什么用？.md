两百秒学IT，很多人天天上网却总搞不懂IP地址、子网掩码到底有什么用。今天咱们用三分钟把IP地址的核心知识一次性讲透。咱们先搞懂IP的基础定义，IP地址全称互联网协议地址，是网络世界里的设备门牌号。它有两个核心作用，一是标识设备所属的网络，二是标识这个网络里某一台具体的主机。简单来说就是在互联网中，不管你的手机、电脑还是家中的智能电视、监控摄像头，每一台连接互联网的设备都必须要有这个门牌号，才能够精准的找到彼此，完成数据通信。我们现在最常用的IP版本叫做IPv4，也就是互联网协议第四版，它的本质是一串三十二位的二进制数，也就是三十二个连续的零和一组成的。

但人类记忆一长串的零和一效率太低，于是有了更友好的表示方式，就是把三十二位拆成四段，每段八位，中间用点隔开，再把每段二进制转化成十进制数字，这就是我们天天见到的点分十进制格式，比如我们常见的一九二点一六八点一点一。IP地址不是一串随机的数字，它的内部有清晰的分层结构，主要由网络位和主机位两部分组成。例如一九二点一六八一点幺零这个IP地址，我们用生活中的事物来举例，前面的一九二点一六八点一就是网络位，网络位相当于小区的街道地址，小区内所有的住户都共用一个街道地址，这就好比在同一个局域网内的所有设备，它们的网络位完全相同。而后面的一零是主机位，主机位就相当于具体的楼栋加房间号，在同一个小区内，楼栋加房间号是唯一的，这就好比在同一个局域网内，每台设备的主机位必须唯一，不能重复。

那怎么区分哪部分是网络位，哪部分是主机位呢？靠的就是和IP地址成对出现的子网掩码，子网掩码和IP地址的格式完全一致，也是由三十二位二进制数组成，规则非常简单，掩码里数字连续为一的部分对应IP地址的网络位，数字为零的部分对应IP地址的主机位。咱们举个最常见的例子，比如这个IP地址一九二点一六八一点一百，搭配子网掩码二五五点二五五点二五五点零，子网掩码前三段都是二五五，说明IP地址的前三段一九二点一六八点一就是网络位，掩码的最后一段是零，那说明IP地址的最后一段一百就是主机位。这里有个重要的知识点，就是CIDR无类域间路由表示法，也就是我们常看到的IP地址加斜杠加数字的表示格式。

由于传统IP地址分为A、B、C三类，网段划分太死板，造成大量的IP地址浪费，而CIDR彻底打破了这个限制，它用IP后的数字标记网络位的长度，比如一九二点一六八一点零斜杠二十四，就代表前二十四位是网络位，剩余的八位是主机位。我们可以通过调整这个数字灵活控制网段大小，它也是现代网络组成的核心基础。另外还有一个知识点就是VLSM可变长子网掩码，它是CIDR技术的延伸，核心逻辑是按需分配。举个简单例子，网络管理员拿到一个一九二点一六八一点零杠二十四位这么一个网段，要给三个部门分配IP，销售部有一百台设备，那分配一个杠二十五位子网，可以容纳一百二十六台主机，行政部二十台设备，分配斜杠二十七的子网。可容纳三十台主机。财务部四台设备，分配斜杠二十九子网，可容纳六台主机。

通过 VLSM，我们能在同一个主网段内，用不同的掩码长度来划分子网，最大限度的避免 IP 地址的浪费，那也是现代企业组网的核心技术之一。最后总结一下，IP 地址是网络设备的数字门牌号，通过网络位与主机位的分层，实现精准寻址。子网掩码界定了两者的边界，而 CIDR 与 VLSM 则让网段的划分更灵活，大幅减少了地址的浪费。那掌握这些关于 IP 地址大部分知识你就了解了。好了，今天的视频就到这里，我们下期再见。
