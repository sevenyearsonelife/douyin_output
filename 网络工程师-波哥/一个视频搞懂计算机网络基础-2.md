来，一秒教会你们计算机网络。这是一个 IP 地址，它有四组数字，中间用点分开，相当于你的电话号码。底下这个是子网掩码，它表示 IP 地址的网段，意思是前三位一样，那就属于同一个网段，可以直接通信。比方说你随便找两台电脑，中间用一根网线连接起来，这时候它们是不能互相连通的，你得配置一个 IP 地址。比方说左边是幺九二点幺六八点幺点幺，右边是一九二点一六八点一点二，因为前三位都一样，这样它们就可以直接通信。这个是 IP 地址的配置界面，第一个是 IP 地址，第二个是子网掩码，第三个是网关，网关后面再讲。配置完成之后，用电脑一给电脑二发送一个数据包看看，可以看到数据包发给电脑二，电脑二收到并发送返回包，电脑一收到返回包，就说明连接建立成功了。那么有什么用呢？

就好比你可以直接共享文件夹，实现文件互传，也可以开启远程桌面，实现控制另一台电脑，这就是计算机网络最简单的组成。如果说此时来了第三台电脑，很明显没地方接入，此时就需要一台交换机，所有电脑全部连接交换机，这样就可以让多台电脑互相访问。这里把第三台电脑 IP 设为幺九二点幺六八点幺点三，然后用第二台电脑给它发数据包看一下，可以看到数据包先发送给交换机，交换机可不知道是给谁的，它只能分发给所有电脑，左边电脑一看数据包不是给它的直接丢弃，然后第三台电脑发送返回包告诉第二台电脑，它收到了，那么这就是一个同网段的局域网，比如学校电脑教室里，四五十台电脑就处在同一个网络内，所以教师机可以控制你们所有的屏幕。

接下来注意看，此时我加入第四台电脑 IP 设为幺九二点幺六八点二点幺，注意这次前三位不一样了，那么此时它和其他三台可以互相连通吗？答案是不能连通，因为 IP 地址不在同一个网段，这是因为 IP 地址是唯一的，如果两台电脑 IP 地址一样就会冲突，并且 IP 地址范围是零到两百五十五这个区间，所以要想跨网段连通，就得使用路由器，路由器的作用就是让不同网段进行通信。这里我加一台路由器，下边端口连接电脑，上边端口连接交换机，然后我们需要进行配置，下边端口 IP 设为幺九二点幺六八点二点二五四，上边设为幺九二点幺六八点幺点二五四，这个就是网关地址，还记得前面网关地址吗？在下边电脑网关就填二点二五四，其他电脑就填一点二五四，意思就是说，如果要访问其他网段，就走各自的网关。

来看一下，用二号电脑发送数据包，可以看到先发给交换机，交换机依然傻瓜分发，然后路由器收到了，发回一个返回包，此时链路就打通了。二号电脑直接发送数据包，交换机直接给路由器，路由器直接给四号电脑，然后原路返回，这样一套流程就完成了。那么这就是最基础的计算机网络，视频中是 IPv 四地址，以后会逐渐普及 IPv 六。如果你感觉每台电脑配 IP 太麻烦，于是就有了 DHCP，这也解释了为什么我们手机电脑连上路由器就能用，这就是本期内容，我们下期再见。
