天天刷网页的你有没有好奇过，输入网址到页面加载，背后到底发生了什么？整个过程分为八步。第一步，输入网址。我们敲下的网址学名是 URL，也就是统一资源定位符。浏览器会先校验格式，提取其中的协议、域名等核心信息。第二步，寻找地址。浏览器会先翻查本地的地址备忘录，依次检索浏览器缓存、系统 DNS 缓存与 hosts 文件，优先就近获取服务器的 IP 地址。第三步，DNS 查询。如果本地没有对应缓存记录，浏览器就会向本地 DNS 服务器发起域名解析请求。本地 DNS 会开启逐级问路模式，依次访问根、顶级、权威域名服务器，最终拿到对应的 IP 地址并返回浏览器。第四步，建立连接。拿到 IP 地址后，浏览器与服务器通过三次握手建立 TCP 连接。

如果是 HTTPS 协议，还会完成 TLS 握手，协商加密规则，搭起安全的数据传输通道。第五步，发出请求。连接稳定搭建好之后，浏览器会向服务器发送 HTTP 请求报文，里面打包了请求方法、请求头、 Cookie 等信息，明确告知服务器需要的页面资源。第六步，服务器处理与回应。服务器收到请求后，会按需执行业务逻辑，查询数据库，生成对应的页面资源，再通过 HTTP 响应报文返回，状态码两百就代表请求顺利完成。第七步，渲染页面。浏览器接收到 HTML 文件后，先解析生成 DOM 树，再结合 CSS 样式生成渲染树，随后完成布局与绘制，逐步把文字、图片等元素还原到屏幕上。第八步，加载完成。当页面所有静态资源全部加载解析完毕，浏览器结束加载状态，完整的网页就正式呈现在我们眼前。

以上就是输入网址到页面加载的全流程，看似眨眼完成的操作，背后是多个网络环节的精密配合。好了，这就是今天的全部内容，我们下期再见。
