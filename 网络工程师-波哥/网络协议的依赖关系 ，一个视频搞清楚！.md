来，你告诉我网络游戏用的是 UDP 还是 TCP？我们日常使用的各种网络服务，无论是浏览网页的 HTTP 或 HTTPS，传输文件的 FTP，还是解析地址的 DNS，支撑直播的 RTMP，本身并不负责搬运数据，只定义内容与规则，而真正的传输工作则交给 TCP 与 UDP 来完成。TCP 像是一位严谨的物流管家，确保每一份数据包裹有序、完整、可靠的抵达，适合网页、文件传输等追求稳定的场景。UDP 则像是一位敏捷的闪电信使，不求确认，只管送达，以速度优先，服务于 DNS 查询、实时音视频等注重低延迟的需求。简而言之，上层协议决定传什么与怎么传，TCP 与 UDP 负责传送到位，二者各司其职，又紧密协作。好了，网络游戏到底用的是 TCP 还是 UDP 呢？
