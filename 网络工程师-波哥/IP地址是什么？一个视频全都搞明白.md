你每天都在用，但你可能不认识它。IP地址是什么？五分钟带你了解它的一切。IP地址的全称是 Internet Protocol Address，即互联网协议地址。核心作用是唯一标识互联网中的某个网络及该网络内的一台主机。就像每个房子都有专属门牌号一样，IP地址就是设备在网络世界中的门牌号。在庞大的互联网中，每一台联网设备，无论是手机、电脑还是家用智能电视、摄像头，都必须拥有这样一个门牌号，才能彼此定位并实现数据通信。目前我们最常用的 IP 地址版本是 IPv4，也就是互联网协议第四版。它的标准形态是三十二位二进制数，由三十二个零和一组成。但人类对三十二位零和一组成的串难以识别记忆。

因此为了简化记忆，我们将其拆分为四段，每段八位，段与段之间用圆点分隔，再把每段二进制数转换成十进制数，这就是我们日常看到的点分十进制表示法，例如幺九二点幺六八点幺点幺。每段八位二进制数对应的十进制范围是零到两百五十五，这是因为八个一组成的二进制数幺幺幺幺幺幺幺换算成十进制恰好是两百五十五。所以只要看到 IP 地址中出现两百五十六、三百等超出这个范围的数字，就能判断该 IP 地址是错误的。IP 地址并非随机的流水号，其内部有着清晰的逻辑结构，主要分为网络位和主机位两部分。其中网络位用于标识设备所在的网络，类似我们生活中的小区地址，同一网络内所有设备的网络位完全相同。主机位则用于区分网络内的具体设备，好比小区里的门牌号，同一网络内的设备主机位必须唯一，不能重复，否则会出现网络冲突。

那如何界定 IP 地址中哪部分是网络位，哪部分是主机位呢？答案是子网掩码。子网掩码同样采用三十二位点分十进制格式，与 IP 地址一一对应，区分规则十分简单，子网掩码中数字为两百五十五的部分，对应 IP 地址的区域就是网络位，数字为零的部分，对应 IP 地址的区域则是主机位。举个例子，若 IP 地址为幺九二点幺六八点幺点幺零，子网掩码为二五五点二五五点二五五点零，由于子网掩码前三段均为两百五十五，说明 IP 地址的前三段幺九二点幺六八点幺是网络位，最后一段时是主机位。

子网掩码二五五点二五五点二五五点零转换成二进制后是二十四个连续的一，基于这一特性衍生出了 IP 地址与子网掩码的简化表示方式，CIDR 格式，即通过 IP 地址网络为长度来描述网络，比如幺九二点幺六八点幺点零斜杠二四，相比完整书写 IP 地址加子网掩码更简洁高效，目前已广泛应用于各类网络配置中。其中斜杠二四代表前二十四位为网络位，后八位为主机位，后八位理论上可提供两百五十五个地址，但实际该网络最多只能容纳两百五十四台设备，因为两百五十五对应的地址是预留广播地址，无法分配给具体设备使用。由此可见，子网掩码的核心作用是划分网络规模，决定一个局域网内可同时接入的网络设备数量上限。接下来我们重点了解 IP 地址的核心分类。

IPv四地址按第一段十进制数值可分为 A、B、C、D、E 五类，每类用途不同，日常场景中以 A、B、C 类最为常用。另外一个重要的分类概念就是公网 IP 地址和私网 IP 地址。公网 IP 地址相当于设备在互联网世界中的全球唯一身份证，由网络运营商分配，可直接在互联网中被路由和访问。私网 IP 地址则是专门为内部网络预留的地址段，适用于家庭、公司、学校等局域网环境，无法直接接入互联网。我们认。常使用的手机、电脑，获取的都是路由器分配的私网 IP。当设备需要访问外网时，路由器会通过 N A T 技术网络地址转换技术，将私网 IP 转换成功网 IP 后再发送请求，实现外网访问。I P 地址家族中还有几个特殊地址需要我们重点掌握。第一个是一二七点零点零点一，被称为回环地址，代表设备自身。

无论电脑是否接入网络，Ping 这个地址都能连通，常被程序员用于测试本地网络程序的运行状态。第二个是零点零点零点零，含义相对抽象，通常代表任意地址或本机所有 I P。若在服务器上配置程序监听零点零点零，意味着接收来自任意网卡的外部连接请求。第三个是二五五点二五五点二五五点二五五，属于受限广播地址。向这个地址发送数据，就好比在村口用大喇叭喊话，同一局域网内的所有设备都能接收到这条消息。前面我们一直在探讨 I P v 四，但 I P v 四地址总数仅四十三亿个，早已面临地址枯竭的问题。尽管借助 N A T 技术暂时缓解了地址紧张问题，但这并非长久之计。因此 I P v 六应运而生。
