两台计算机要如何通信？用一根网线把它们连接起来，就组成了一个最简单的网络。再给它们分别配一个 IP 地址，它们之间就可以互相通信，比如传输文件、发送消息等。那什么是 IP 地址？IP 地址由四组零到两百五十五的数字组成，中间用点分开，它相当于手机号码，打电话找人就要先知道对方号码，IP 地址的功能也是如此。比如左边电脑 IP 是幺九二点幺六八点幺点幺，右边是幺九二点幺六八点幺点二，只要两个 IP 属于同一个网段，就能直接通信。那到底什么是同一个网段？

我们先从 IP 地址的分类讲起，常用的 IP 地址分为 A、B、C 三类，其中幺点零点零点零到幺二六点二五五点二五五点二五五点二五五是 A 类地址，幺二八点零点零点零到幺九幺点二五五点二五五是 B 类地址，幺九二点零点零点零到二二三点二五五点二五五点二五五点二五是 C 类地址。三类地址的核心差异在于可容纳的网段数量和设备数量不同。在这三类地址里，各有一段专门预留做局域网内使用的地址，叫做私有 IP 地址。简单来说，局域网就是不直接接入互联网的内部网络，比如家庭、办公室的内网。我们开头例子里幺九二点幺六八开头的两个地址就属于 C 类私有地址，C 类地址默认前三组数字相同，就属于同一个网段，可以直接互通。为什么 C 类地址看前三组数字？

这就要提到子网掩码，它的作用就是划分 IP 地址里的网络位和主机位，网络位就是用来区分 IP 地址是属于哪个网段的。这里有一点我们要注意，IP 地址不能单独使用，它必须要有一个子网掩码搭配使用。那如何知道 IP 地址属于哪个网段的？比如 C 类地址默认的子网掩码是二五五点二五五点二五点零，IP 地址对应掩码中二五五的部分，比如幺九二点幺六八点幺就是网络位，所以前三组网络位一样就属于同一个网段，像幺九二点幺六八点一点一和幺九二点幺六八点一点二就是同一个网段，而幺九二点幺六八点幺六零点幺就跟它们不是一个网段，因为前三组不同。搞懂网段的概念，我们再回到最开始的两台电脑，正常的 IP 配置应该是这样，但配置 IP 时通常还有一项网关地址，你可以把它理解成当前网段的出口，一般就是路由器的内网 IP 地址。

路由器的作用就是让不同网段之间可以互相通信。举个例子，如果有一台电脑的 IP 是幺九二点幺六八点幺零点幺和幺九二点幺六八点二零点幺的设备不在同一网段，哪怕都接在同一台交换机上，也没法直接通信。这时候加入一台路由器，分别接入两个网段，给路由器的两个网口分别配置对应网段的 IP，比如左边网口设为幺九二点幺六八点幺零点二五四，右边设为幺九二点幺六八点二零点二五四，再把两台电脑的网关分别设为对应路由器网口的 IP，它们就能互相通信了。对了，如果大家想看更多关于 IT 方面的科普视频，比如网络技术、信息安全或者人工智能方面，可以去抖音精选 APP 观看我的视频，条条都是宝藏视频。如果想让内网设备连上互联网，只要把路由器的 WAN 口接到光猫上就行。
