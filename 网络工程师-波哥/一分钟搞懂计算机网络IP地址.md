来，一秒教会你们计算机网络。这是一个 IP 地址，它有四组数字，而这是跟它经常一起出现的，它们都有什么用？今天我们用一分钟搞定 IP 地址的全部知识。IP 地址是指互联网协议地址，又译为网际协议地址，用来唯一标识互联网中的一个网络以及该网络内的一台主机。就像每个房子都有专属门牌号，IP 地址就是设备在网络世界里的门牌号。在浩瀚的互联网世界里，每一台联网的设备，无论是你的手机、电脑，还是家里的智能电视、摄像头，都需要一个这样的网络门牌号，才能相互找到对方并进行通信。我们现在最常用的 IP 地址版本叫做 IPv4，也就是互联网协议第四版，它的标准形态是三十二位二进制数，也就是三十二个由零和一组成的数字。

但人类看三十二个零和一会难以记忆，所以为了方便记忆，我们把它分成四段，每段八位，中间用圆点隔开，再将每段的二进制数转换成十进制，这就是我们常见的点分十进制表示法，比如一九二点一六八点一点一。每一段八位数字的范围最小是零，最大是两百五十五，因为八个二进制一换算成十进制就是两百五十五。IP 地址不是简单的一串数字，它内部有着清晰的逻辑结构，由网络位和主机位两部分组成。网络位用来标识设备所在的网络，相当于我们小区的街道地址，在同一网络内的所有设备，网络位是相同的。而主机位用来标识网络内的具体设备，相当于我们的门牌号，同一网络内的设备，主机位必须唯一，不能重复。那怎么区分哪部分是网络位，哪部分是主机位呢？

靠子网掩码，子网掩码也是三十二位点分十进制格式，和 IP 地址一一对应，规则很简单，子网掩码中二五五对应的 IP 地址部分是网络位，零对应的部分是主机位。举个例子，IP 地址幺九二点幺六八点幺点幺零零，子网掩码二五五点二五五点二五五点零，子网掩码前三段是二五五，对应 IP 地址的前三段就是网络位幺九二点幺六八点幺，最后一段是主机位幺零零。子网掩码二五五点二五五点二五五点零转换成二进制是二十四个一，这就有了 IP 地址和子网掩码更简化的写法，CIDR 格式，即用 IP 地址加网络位长度表示网络，比如幺九二点幺六八点幺点零斜杠二四，比写完整 IP 加子网掩码更简洁，现在网络配置中普遍使用这种格式。

幺九二点幺六八点幺点零斜杠二四表示前二十四位是网络位，后八位是主机位，后八位总共可容纳两百五十五个地址，但这个网络内最多能连接两百五十四台设备，因为两百五十五是预留的广播地址，不能分配给具体设备。所以子网掩码的作用就是划分网络大小，决定一个局域网内最多能同时接入多少台网络设备。接下来我们要了解 IP 地址的一个关键分类，公网 IP 地址和私网 IP 地址。公网 IP 地址就像是你在互联网世界里的全球唯一身份证号，由运营商分配，可直接在互联网上被路由和访问。私网 IP 地址则是为内部网络，比如家庭、公司或学校局域网预留的地址段，无法在互联网上直接使用。

你家里的手机、电脑获取到的就是路由器分配的私网 IP，当设备要访问外网时，就需要用到路由器上的 NAT 技术，NAT 网络地址转换，就是解决公网 IP 地址不够用的问题。家里、公司的手机、电脑等设备用的都是内网私有 IP，没法直接连互联网，NAT 能把这些私有 IP 转换成一个路由器的公网 IP 地址，这样内网的设备就能通过路由器上网了。讲到这里，我们一直围绕 IPv4 展开，但 IPv4 地址总数只有四十三亿个，早已枯竭。虽然我们用 NAT 技术延长了它的使用时间，但这并非长久之计，于是 IPv6 应运而生。IPv四是三十二位，而IPv六是一百二十八位，这个数量大到什么程度？有个著名的比喻，IPv六可以让地球上的每一粒沙子都拥有一个独立的IP地址。IPv六不仅地址数量近乎无限，还更安全、速度更快、配置更简单。

目前我们仍处于IPv四和IPv六共存的过渡期，但你会发现，现在的手机四G、五G网络以及家庭宽带，都已经分配了IPv六地址。未来，每一台冰箱、每一盏路灯都能拥有一个全球唯一的公网IP，这将成为万物互联的基础。好了，本期的分享就到这里，我们下期见。
