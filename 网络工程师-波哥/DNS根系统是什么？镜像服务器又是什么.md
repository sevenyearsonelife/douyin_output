这个你知道是什么吗？今天我们来了解域名系统。百分之九十九的人上网都做过，打开浏览器，输入网址，敲下回车，网页瞬间就能加载出来。但大家有没有好奇过一个问题，我们输入的这串网址到底是什么？首先我们搞清一个问题，在网络世界里，每一台接入互联网的服务器和设备都有一个独一无二的 IP 地址，就相当于现实世界里的详细门牌号。我们访问任何网站，本质上都是先找到对应服务器的 IP 地址，和它建立稳定的数据连接，才能获取数据。但长串数字难记又容易输错，这就诞生了域名方案。简单来说，域名就是互联网上网站的文字门牌号，它用人类易读易记的字符组合替代了数字 IP 地址。我们平时输入的网址核心就是域名，域名使用字符形式的地址更符合人的记忆习惯，也让网络访问变得更简单了。

域名采用的是层级化的树状结构，级别从右往左依次降低，最右边的是顶级域名，比如我们常见的点 com、点 cn 等，由全球统一的专门机构管理。再往左是二级域名，通常是企业或机构的专属名称，也是一个域名最核心的标识。再往左比如三 w，就是三级域名，用来区分不同的服务站点。那 DNS 到底是什么？它全称域名系统，是互联网里负责域名与 IP 地址相互映射的分布式数据库系统，核心功能就是域名解析，你输入域名，它自动翻译成设备能识别的 IP 地址，帮设备找到对应的服务器，是支撑互联网正常访问的核心基础服务。DNS 不是单台设备，而是一套分层协作的分布式体系，主要由四部分构成，递归解析器、根域名服务器、顶级域名服务器和权威域名服务器，每一个层级的服务器都有单独的功能，这个我们下期讲。

根服务器是 DNS 系统的核心，是所有域名解析的最高入口。目前全球共有十三组逻辑根服务器，以 A 到 M 命名，由全球不同地区的机构独立运营。理论上，任何域名解析都要先通过它获取顶级域的查询入口，是互联网的核心枢纽。为提升根服务器的访问速度与可靠性，全球部署了大量根镜像服务器，它们通过任播技术共享同一 IP，请求会被自动路由到最近的镜像节点，镜像与主根节点实时同步数据，返回一致的查询结果，既降低了访问延迟，也避免了单点故障，让整个 DNS 根系统更稳定高效。总的来说，DNS 系统核心功能是实现域名与 IP 地址的双向映射，让我们能用易记的域名便捷访问网络资源，同时它还能支撑智能分流、负载均衡等扩展能力，是互联网稳定高效运行的基础。好了，这就是今天的全部内容，下期我们看看 DNS 的工作原理，再见。
