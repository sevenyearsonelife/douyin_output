VLAN 和 VxLAN 是什么？大家好，今天我们来聊聊网络里容易混淆的两个技术。我们先来搞清 VLAN 是什么。假如现在有一个一千台电脑的公司，所有电脑都连在同一个交换网络上，就会出现三个致命问题。第一，广播风暴。一台电脑发一个广播消息，全公司一千台电脑都要接收处理，网络会被堵死。第二，安全隐患。财务部的电脑和前台电脑在同一个网络，任何人都能轻易访问财务数据。第三，管理混乱。员工换部门时需要重新拔插网线，调整物理线路，运维工作量巨大。VLAN 就是为了解决这些问题而生的技术，它又叫虚拟局域网，是一种将物理局域网从逻辑上划分为多个独立广播域的技术。划分 VLAN 前，大家就像在一个超大的办公室里，相互能随意走动，也能听见彼此说话。现在划分 VLAN 后，就等于将这间超大的办公室隔开成了一个个独立的小办公室。

由于墙壁的阻隔，不同办公室之间就不能随意走动，也听不见对方说话了。VLAN 主要有四大核心功能。一，隔离广播域。划分 VLAN 可将一个大型广播域网络拆分为多个小型网络，缩小广播传播范围，有效防止广播风暴产生，保障网络流畅运行。二，保障网络安全。不同 VLAN 内的设备默认无法直接通信，可实现不同组别数据的有效隔离，规避数据互通带来的安全风险。三，网络管理灵活。无需局限设备物理安装位置，可根据员工部门、工作职能进行逻辑化网络分组，适配性更强。四，简化运维部署。员工调换部门时，只需在交换机端修改对应的 VLAN 配置，无需调整更换物理网线，大幅简化网络调整工作。但是 VLAN 的两大缺陷已经不适应现代大型网络的发展需求了。

第一，IEEE 八零二点一 Q 标准规定 VLAN ID 只有十二比特，这意味着一个网络最多只能划分出四千零九十六个 VLAN。对于大型数据中心、云服务商或多租户环境来说，这个数量完全不够用。第二，VLAN 本质是二层网络技术，难以跨越三层 IP 网络。这就导致一些关键业务，比如虚拟机的动态迁移，通常要求源和目标在同一个二层广播域，即同一个 VLAN。当业务需要在不同网段或不同数据中心之间迁移时，就使得难以实现。基于这些问题，VxLAN 应运而生。VxLAN，Virtual eXtensible LAN，中文叫虚拟可扩展局域网，是一种基于 IP 网络的 overlay 网络技术。它将二层以太网帧封装在 UDP 数据包中进行传输，从而在三层 IP 网络之上构建一个虚拟的二层网络。

如果说 VLAN 是在一个大楼里用玻璃隔断墙分房间，那么 VxLAN 就是在全国甚至全球范围内，用虚拟隧道把不同城市、不同大楼里的房间连接成一个大的虚拟办公室。无论你在北京还是上海的办公室，都感觉像是在同一个物理局域网里。那 VxLAN 具体是怎么工作的呢？我们还是用场景来说明。北京数据中心有一台虚拟机 A，上海数据中心有一台虚拟机 B，它们属于同一个 VxLAN 网络，VNI 是一万，这个编号就类似 VLAN ID。当虚拟机 A 给虚拟机 B 发消息时，北京的 VxLAN 网关设备会先收到这个原始的以太网帧。然后它会给这个帧加上一个八字节的 VxLAN 头，写上 VNI 等于一万，再加上 UDP 头、IP 头和以太网头，把整个二层帧封装成一个三层的 UDP 包。

这个包通过互联网传到上海的 VxLAN 网关设备，它会把所有外层的头都去掉，恢复出原始的以太网帧，再发给虚拟机 B。整个过程中，虚拟机 A 和 B 完全感觉不到中间的三层网络，他们以为自己就在同一个局域网里。这就是为什么虚拟机可以跨数据中心无缝迁移，IP 地址和网关都不用改，业务完。完全不中断。好了，来总结一下，VLAN是传统局域网的基础隔离技术，用玻璃隔断的方式解决了物理网络内的广播和安全问题，适合中小型网络。VXLAN是云计算时代的大二层技术，用虚拟隧道的方式解决了VLAN数量不足、虚拟机迁移受限和多租户隔离的问题，适合大型数据中心和云环境。今天的内容就到这里，如果大家有什么问题，欢迎在评论区留言交流，我们下一期来详细了解一下VXLAN，再见。
