今天我想用十分钟的时间来告诉大家如何从零上手 Linux。可能说到 Linux，大家首先想到的是开源免费，系统安全稳定，并且在服务器上被广泛使用。而且 Linux 对硬件的要求极低，在旧电脑上跑起来可以说毫无压力，尤其和现在的 Windows 全家桶比起来，速度真的是天壤之别。其实 Linux 最吸引我的一点是它极高的可定制性，你可以根据自己的喜好去定制系统的任何功能，让它完全贴合你自己的使用习惯，大幅提升工作效率。虽然一开始可能比较折腾，但这点投入绝对是值得的。在 Linux，你拥有整个系统完全的掌控权，想装什么配置什么，都由你自己决定。我们不用担心哪天系统更新会给你塞入一堆没用的功能，也不用担心系统在后台偷偷上传你的数据。

而且在自己动手配置 Linux 的过程中，我们一定会接触到许多底层的概念，尤其是亲自去做分区、配置网络、设置引导程序的时候，我们会更清晰的了解到操作系统是怎样运作的。可能很多人觉得 Linux 只适合部分高端玩家，其实完全不是这样的。现在主流的 Linux 发行版基本都提供了非常友好的图形界面，我可以保证大家在第一次接触的时候也可以快速上手，至少日常使用不会有任何问题。那说了这么多，我们应该在哪里下载和安装 Linux 呢？这里我们先要区分一个概念，严格来说 Linux 本身只是一个内核，也就是 Linus 当年写的与硬件交互最核心的部分。显然光有一个内核是没有办法直接使用的，因此我们需要去下载一个叫做 Linux 发行版或者叫 distro 的东西。

发行版包含了 Linux 内核，并且打包好了各种工具软件、桌面环境，还有一个方便管理和安装软件的包管理器。像我们平时听到的 Ubuntu、Fedora、Arch，其实都是不同 Linux 的发行版。尽管目前依然在维护的发行版有上百种，但绝大多数的发行版其实都源自于两个经典的派系 Debian 和 Arch。如果你想让系统永远保持最新，第一时间体验到新功能，那可以考虑基于 Arch 的发行版，但如果你更看重稳定性，那基于 Debian 的发行版可能是更合适的选择。很多人可能会问，哪一个发行版最好？我到底应该安装哪一个？其实这个问题没有标准答案，因为无论是哪一个发行版，都可以根据你的需求进行深度定制。

如果你是第一次接触 Linux，我建议从简单、稳定、容易上手的发行版开始，比如 Linux Mint，它的界面和 Windows 很像，几乎没有学习成本，或者 Ubuntu，它依然是当前最受欢迎的发行版之一。在这里呢，我们就以 Linux Mint 为例来给大家演示一下。我们先去它的官方网站下载系统镜像文件。下载完成之后，我们可以安装在虚拟机或者制作一个 Live USB 来体验，这样我们可以在真正安装之前完整的试用一下整个系统。相比虚拟机，用 Live USB 的好处是系统直接运行在你的真实硬件之上，性能明显会好很多。我们还可以顺便测试一下系统的兼容性，看看 WiFi、显卡、触摸屏这些硬件能否正常工作。要制作一个可引导 U 盘，我们可以用一个叫 Etcher 的跨平台工具。

然后我们运行 Etcher，插入 U 盘，选择下载好的 ISO 文件，然后点击 Flash 即可。重启电脑之后，我们选择从 U 盘启动，等系统加载完成之后，我们就会进入到一个中规中矩的图形界面。在 Linux 下我们叫它桌面环境，使用起来和其他操作系统大同小异。在这里你可以找到文件管理器、浏览器、更改系统设置、主题、屏幕的分辨率等等。绝大多数的硬件，比如 WiFi 和蓝牙，不需要任何配置都能正常使用。在 Linux 下我们通常不需要安装驱动，因为驱动是 Linux 开源内核的一部分。当然也有少数例外，比如如果你不幸使用的是英伟达显卡的话，我们依然需要安装官方的闭源驱动才能让显卡正常工作。当我们试用完整个系统觉得还不错的话，接下来就可以。正式开始安装了。

安装过程其实非常简单，我们只需要填一些基本信息，然后一路下一步下去，整个过程大概需要花几分钟的时间，这里我们就直接略过了。那装好系统之后，我们应该怎么安装常见的各种应用呢？这点和 Windows、Mac 不太一样，主要有两点原因。第一是软件安装的方式，第二次有些软件可能压根没有 Linux 版本，这个时候呢我们就不得不找一些替代品了。当然最最简单的软件装方式就是使用发行版自带的应用中心或者软件管理器，虽然它有一些限制，但确实是最方便省事的。我们可以在这里找到一些常见的跨平台应用，也包括私有软件，比如 Nvidia 的驱动，通常只需要点几下鼠标，我们就可以搞定应用安装。

如果你之前是 Windows 的用户，那么有些软件可能需要寻找替代方案，比如 Office 办公套件，虽然它可以通过兼容层或者虚拟机来运行，但配置起来十分麻烦。更简单的方法是直接使用开源的 OpenOffice 或 LibreOffice 来代替，基本可以满足日常的使用需求。图形设计的软件比如 Photoshop、Illustrator 可以用 GIMP 和 Inkscape 来替代。音视频编辑的软件比如 Premiere、Audition 可以用 Kdenlive、Audacity 来替代。当然常见的浏览器像 Chromium、Firefox、Brave 也都可以在应用中心找到。在游戏方面，之前被经常吐槽的 Linux 游戏兼容性，其实在 Steam Deck 发布之后有很大的改善。

现在越来越多的游戏开始支持 Linux，像 Proton、Wine 这些兼容层在这几年也进步了不少，至少 Steam 上的绝大多数游戏都可以运行的非常流畅，游戏体验完全可以说不比 Windows 差，甚至还要更好。所以说 Linux 在日常使用中其实是完全没有问题的。另外之前我们只是体验了 Linux Mint 自带的 Cinnamon 桌面环境，但选择远不止于此，我们完全可以试试看其他不同风格的桌面环境，比如 GNOME、KDE、XFCE 等等，这也正是使用 Linux 的乐趣所在。如果我们不满意系统自带的桌面环境，比如它的界面或是提供的一些系统应用，我们甚至可以卸载整个桌面环境，而是单单使用轻量级的窗口管理器，再搭配上自己喜欢的工具，打造一套完全属于自己的工作流。

如果再配合动态的窗口管理器，比如 Tiling Window Manager，我们完全可以做到只使用键盘来高效的切换任务。当然这些完全还是看个人的喜好，如果大家感兴趣的话，我们之后可以单独出一期视频来讲讲。那么接下来我们就来安装另一个桌面环境来试试看，这也是到目前为止我们将要第一次用到命令行。我们试着用它来安装 KDE 桌面环境，来尝试一下稍微进阶一点的软件安装方法。在第一次运行包管理工具的时候，我们需要用到这个经典命令 sudo apt update。sudo 代表以超级用户权限运行命令，因为安装系统软件的时候需要用到系统的最高权限。apt 是 Linux Mint 也是 Ubuntu、Debian 系统的包管理工具，它的作用只是让本地软件列表和服务器保持同步。

如果不执行这一步，在后续安装软件包的时候，可能会出现找不到或者安装到旧版本的错误。这个命令本身不会安装任何软件，通常只需要运行一次即可。接下来我们可以用 sudo apt install kde-plasma-desktop 来安装 KDE，后面的包名很长，显然我们不需要死记硬背，网上一搜就出来了。在安装的末尾，系统可能会弹出一个界面，让我们选择需要使用的 Display Manager。Display Manager 大家可以暂时理解成 Linux 的登录界面，没错，在 Linux 下的登录界面也是可以随意替换的，而 LightDM 和 SDDM 是两种不同风格的登录界面，这里选什么其实没有那么重要，我们直接回车即可。

接着我们登出当前用户，再选择 KDE 桌面环境重新登录，然后我们就会看到一个全新的 KDE 桌面环境。那讲到这里可能有人会问，我们真的要用到命令行才能使用 Linux 吗？答案是不一定。我相信桌面环境提供的各种可视化程序足以满足大多数日常使用的需要。但另一方面，命令行一定能够让我们事半功倍，尤其是需要完成一些复杂的操作或者需要深度定制系统的时候，命令行可以说是绕不开的。Linux 和 Windows、Mac 不太一样，我们知道 Linux 是围绕着 shell 展开的，而不是以图形界面为主，甚至图形界面都不是必须的。比如在服务器环境中，我们根本不需要桌面环境，它反而会占用额外的系统资源。因此命令行成为了 Linux 几乎通用的人机交互方式。

比如在所有的 Linux 发行版中，我们可以用 df 查看磁盘空间，用 top 查看系统资源的占用情况，用 ip 命令来查看网络接口信息等等。显然我们没有办法讲到所有的 Linux 命令，但这里给大家提供一个学习思路。现在有五花八门的大语言模型，我们完全可以向它们直接提问。比如我们问它，怎么在当前目录下找到最大的五个文件？对于大多数问题，它应该都能够给出非常详细的答案。我们还可以继续追问，让它详细解释一下每条命令的含义。所以我们在用 Linux 的时候，一定会碰上各种新的概念，这其实挺正常的，因为 Linux 确实要多动手才能慢慢的熟悉和掌握它。另外大家可能会问，这么多复杂的命令我们都要全部记下来吗？

当然不是，命令行只是 Linux 下的一个基础构建，在它的基础上，我们可以给常用的命令创建别名，编写脚本，甚至可以设置全局快捷键来更快捷的用键盘来调用。比如我经常会用到 ffmpeg 给视频添加一个标题，与其每次都去敲一长串的指令，我们完全可以写一个脚本，然后起一个别名直接调用它。虽然写脚本一开始会花点功夫，但可以节省之后大把的时间，毕竟偷懒才是人类的第一生产力对吧？当我们对 Linux 有了一定的了解之后，可以去尝试一些更进阶的发行版，比如 Arch Linux。到那个时候，我们已经能够根据自己的需求去深度定制系统，让整个系统完全贴合我们自己的使用习惯。
