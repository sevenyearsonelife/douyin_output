首先我养这三个 AI 员工用的是 Kimi Cloud，它和 Open Cloud 部署起来的区别在于 Kimi Cloud 直接运行在云端环境里，基本上一键启动，不需要你自己手动安装，也不会被一堆复杂配置劝退，还不用担心漏洞问题导致财产损失。说白了就是不用折腾，也不用花高价找人上门部署了。打开 Kimi 的官网，找到这里的 Kimi Cloud，点击创建，稍等一会儿云端服务就部署好了。点击右侧的设置，我们可以进行编辑 Bot 的名称，打开终端，重启 Kimi Cloud 等操作。想要给飞书配置 Kimi Cloud，方法非常简单，直接提问，可以看到 Kimi Cloud 给了我一份超级详细的配置教程，再配合这份飞书官方提供的文档，操作起来非常方便。

首先来到飞书开放者平台，创建企业自建应用，输入应用名称和应用描述，然后找到添加机器人能力，添加机器人，在权限管理这里点击批量导入导出权限，把这一长串代码复制进去。这些代码呢，就是给机器人开通聊天、云文档等权限的配置信息，我也放到了云文档里，方便大家复制粘贴。点击申请开通，然后点击这里的创建版本，填写一下发布信息，保存并发布。这样我们在凭证与基础信息里就能看到机器人的 App ID 和 App Secret 的信息了。回到 Kimi Cloud 对话框，直接按照它写的教程，替换成这里的 App ID 和 App Secret，把这段代码直接丢给 Kimi Cloud，它就会自己检查是否已安装插件，自动配置并绑定机器人了。

待它自动重启后，我们再回到飞书后台，找到事件与回调，添加接收消息、消息已读、机器人进群、机器人被移除群的事件，然后点击这里的创建版本，重新发布。我们就可以来到飞书，搜索我们创建的机器人，然后跟它对话了。想让它进行角色扮演也非常简单，比如我想让它扮演我的员工，直接跟它说就行。想要定时接收消息，比如像这样，你要搜集每日的热点消息给我，每天八点提醒我，请我查阅你整理的天下要闻、热门资讯消息，可以是 AI 相关的，也可以是科技类相关的，这样一个定时任务就做好了。每天我们都能在飞书上收到它的消息，比如现在的拍摄时间是十一号，它就给我发了今天的天下要闻和午盘策略。直接问它有哪些定时任务，还可以查看现在的定时情况。让它做模拟炒股，帮我整理发票，并统计到飞书多维表格里的方法也是一样的，直接跟它交互，给它提需求就行。
