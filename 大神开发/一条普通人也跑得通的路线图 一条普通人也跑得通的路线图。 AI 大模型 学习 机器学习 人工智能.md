大型语言模型工程 RAG 检索增强生成，让模型知道你们公司的事，RAG 大概长这样。问题到 embedding 到检索相关文档到拼成 prompt 到喂给 LLM 到回答。要做的工程工作主要集中在文档清洗和 chunk 切分，选择 embedding 模型，选向量数据库，Faiss、Milvus、PG Vector 等，rerank 加 query rewrite 提升质量，加上缓存和日志，做成真正可用的系统。现实里百分之八十公司级问答知识库内部助手类需求，RAG 就够了。阶段五，Agent，让模型不只会说，而是会去做。

Agent 本质上是 LLM 加一堆工具，Tool 加一点点规划能力，它通常包含几个组件：Planner 规划步骤，Tools 执行动作，比如搜索调用 API 跑代码，Memory 记住之前的关键信息，Executor 真正去跑，Reflection 复盘自我修正。你可以从最简单的开始，写一个自动写日报 Agent，调用日历任务管理 API，汇总今天事件，生成日报草稿，再慢慢升级到自动分析 Excel，自动拉取数据加生成报告，自动查文献加写书稿。做到这个阶段，你已经从玩玩大模型变成了用大模型搞自动化系统的人。如何利用现有大模型把自己当成有教练的人？以前你自学编程很难遇到一个随叫随到耐心讲解的高级。程序员，现在不一样了。DeepSeek GPT一类的模型就是你的七乘二十四小时教练。
