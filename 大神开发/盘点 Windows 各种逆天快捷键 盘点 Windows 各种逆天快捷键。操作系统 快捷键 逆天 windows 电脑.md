盘点 Windows 各种逆天快捷键。首先是正常区，Windows 加 E 打开文件扒拉器，Windows 加 R 打开运行框，Windows 加 D 显示桌面，Windows 加 L 锁定屏。慢哦，Windows 加 V 打开剪切板，Windows 加 S 打开那个 B 搜索，Windows 加 I 打开设置，Windows 加 X 打开快速链接菜单，Windows 加 Shift 加 S 截屏，Alt 加 F 四关闭窗口，Alt 加 Tab 切换窗口。估计是快捷键内比较普遍的了，尽管没听过也略有耳闻。接下来是冷门区，你或许听过但没用过，Windows 加 K 选择投放装置，Windows 加 P 投影画面菜单，这两个如果不用投屏的话基本上就不会接触。

Win 加加打开或放大放大镜，Win 减缩小放大镜，Windows 加 Escape 退出放大镜，说实话感觉放大镜很少会用到，留着估计就是为了兼容。Windows 加 W 打开小工具，可能是 Win 十一的唯一真实，目前我身边有零个人在用这个东西，我想也不会有人把摸鱼的时间花在这个傻逼玩意上，甚至占了你大半块屏幕。对了话说怎么没有反应？哈？Windows 加 F 打开反馈中心，这个东西或许有人用，但是我觉得配不上一个 Win 键加单键的快捷键。不过反过来想，微软既然敢这么设计一定有它的原因。Windows 加 G 打开 Xbox Game Bar，听说性能是一坨，玩游戏最好不要带上它，不过据说里边的性能检测比任务管理器还准。

Windows 加 H 语音输入，又一个我没用过的功能，但似乎最近风评趋势向正面发展，却依旧很难改变 Win 十一拉完了的情况。下面进入问号区，一般不用的功能或者你没听过的快捷键，不理解但尊重，会放在这里。Windows 加 T 把焦点放任务栏，Windows 加 B 把焦点放任务栏右下角，由于其功能过于别扭，以至于我都不知道怎么描述它们，感觉是那种什么，鼠标坏了非得用键盘然后你别无选择，不然手用鼠标。

Windows 加 Z 窗口对齐布局，Windows 加 Control 加 L 显示字幕，Windows 加 Control 加 S 语音访问，Windows 加 Shift 加 R 录屏，Windows 加 Shift 加 T 截取文字，以上五个都是 Win 十一新增的特色功能，有多特色只有微软最自信，总感觉 Win 十一就是多了很多没用又占位置的 B 功能。Windows 加 Control 加 Enter 讲述人。桌面扫描，讲述人窗口标题级别一，欢迎使用。好了你特么别说了，这个东西既然放在辅助功能，也就是说会有一些身体有障碍的人士使用这个工具，嘻嘻嘻这个讲述人的使用体验也是烂中之烂，你不仅要等它慢慢读，甚至还要学习一套操作方法，简单来说就是槽点太多。

Windows 加 Control 加 F 搜索局域网计算机，依旧 Win 十一建构在远古 NT 内核之上，Windows 加 Pause 打开系统信息，嘻嘻这个应该是不错用的，看你什么时候用而已。最后就是意义不明区，不知道怎么概括了，直接看吧。Windows 加 Q 单击已执行，Windows 加 G 回顾，这俩都是 Copilot 加 PC 还是 AI 加 PC 的功能，微软是这样介绍的。推崇 AI 这块给微软玩明白了，甚至分配到了一个快捷键，像是怕你每次打开很麻烦，实际没什么人用。Windows 加 F 一打开网络帮助，懒得喷，总之没有人会用建议赶紧退出。

Windows 加 Alt 加 Enter 焦点在任务栏时打开任务栏设置，极其合异味的快捷键，首先任务栏设置很少用，其次任务栏设置也可以右键任务栏打开，这个快捷键还需要把焦点放在任务栏才可生效，大众甚至都不知道焦点是什么，就更别讨论这个快捷键了。Windows 加 Alt 加 F 打开反馈中心但不截屏，正常按 Win 加 F 的时候是会截屏的，用于什么提交反馈更方便排查问题，但是你不想要的话你就可以直接按掉。而且就算怕你麻烦，也应该先按 Alt 截屏，不按 Alt 不截屏。Windows 加 Shift 加 Enter 在 UWP 应用内开启全屏，你有 F11 全屏你不用，而且对 UWP 应用也同样生效。

然后除了 Win10 的内置程序那些以外，用户基本上不怎么接触基于 UWP 框架的应用，就很多人习惯了 F11，根本用不上这个东西。总之很多快捷键给我的观感，为了设计而设计，或者纯粹就是为了向下兼容，毕竟 Windows 已经成为很多人和企业的主要操作系统。微软一改又不知道动了谁的小蛋糕，你说这也没办法。所以我的建议是，有条件用 Linux 的就赶紧的吧。
