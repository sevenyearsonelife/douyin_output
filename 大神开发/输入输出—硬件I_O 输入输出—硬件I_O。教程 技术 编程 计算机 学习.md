机除了有 CPU 和内存以外，还有输入和输出的设备，比如键盘、鼠标、显示器、磁盘等，这些统一称为 I/O 设备，分别是 Input Output 的简写。I/O 设备主要分为块设备和字符设备。比如磁盘就是块设备，它的传输是以一个连续的块为基本的传输单位，每个块有独立的磁盘地址，方便读写，互相没有任何关系，也就是从磁盘的不同位置读取，支持随机读写。而比如键盘产生的是一个个的字符，它们按照顺序组成字符流，无法随机读写。我们就以磁盘为例子，I/O 设备一般是由机械部件和电子部件两部分组成，而电子部件称为设备控制器，或叫适配器，它通常是在电脑主板上的。

设备控制器直接控制 I/O 设备，发出命令后，磁盘向控制器发送二进制的比特流，随后带着一个校验码，然后设备控制器内有一个缓存区域，接受这些比特流组成一个块以后，再用受到的校验码检查，无误之后再试图发送到内存中。但是设备控制器不能自己传送到内存，这时候需要 CPU 的指挥。那么 CPU 是如何与设备控制器通信的呢？设备控制器通常有一些寄存器，CPU 通过读写这些寄存器可以发送接收数据，开启或关闭，了解设备状态。那么为了读写，每个设备寄存器都需要一个编号，一种方法是直接赋予专属的 I/O 端口号，所有设备寄存器的端口号组成独有的 I/O 端口空间，而操作系统需要使用特殊的指令，例如将控制寄存器端口号为四的内容传输到 CPU 的寄存器 R0 中，而这和 move 指令中的四指代的是内存的地址。

那么同样的还有 out，将寄存器的值传输给端口号四。这种方式虽然清楚地划分了两个地址空间，但也需要特殊的指令。另一种方式是把端口作为内存中的高地址部分，这样当用 move 指令的地址在这段特殊的地址范围时，其实就在与设备控制器通信，而除此之外就是正常的内存访问了，这称为内存映射 I/O。当然这种需要每次判断地址在哪个范围也有缺点，所以还可以把这两种混合，内存中高地址存储设备控制器中的缓冲区，剩下的控制寄存器拥有单独的 I/O 地址空间。接下来假如设备控制器完成一个块的数据，需要 CPU 的指挥才可以将其运送至内存，并把目的地址指向下一个位置。但是每传送一个块时都需要打断 CPU 来处理，未免太低效了，所以我们需要一个中介叫直接存储器存取，简称 DMA。

在 DMA 中包含几个寄存器，用于存储比如目的内存地址、字节计数，还有一些控制寄存器。CPU 会事先设定好所有读写内容的长度以及目的地址，然后 CPU 就可以干其他事了。而 DMA 首先向设备控制器发出读请求，等设备控制器接收完毕后，DMA 按照内存地址来负责将把数据传送到内存即可，接着把字节计数递减一个单位，内存地址递增一个单位。如果字节计数还是大于零，那么就继续传输数据，等到字节计数到零，DMA 向 CPU 发出信号来结束读取。
