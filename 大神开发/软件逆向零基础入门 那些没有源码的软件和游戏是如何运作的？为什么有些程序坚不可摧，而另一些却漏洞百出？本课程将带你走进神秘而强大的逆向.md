逆向工程是游戏作弊中最重要的一部分。在你能够利用某个系统之前，你必须先发现它的漏洞。游戏黑客会结合一系列工具和深厚的计算机科学知识，系统性地拆解电子游戏。今天我想探讨一些逆向工程背后的基本概念和程序，希望你能坚持看下去，因为说不定你会学到一些新东西。在我们开始之前，今天的视频由 Brilliant. Org 赞助。逆向工程是指分析一个产品或系统以了解其设计方式和工作原理的过程。当你下载一款视频游戏时，你实际上无法访问其源代码。你的游戏极有可能已经被编译成机器码，而机器码对人类来说并不直观易读。当你运行一款视频游戏时，所有重要信息，比如你的生命值、弹药量等，都存储在随机存取内存中。我们主要使用逆向工程来查找这些关键变量的地址，并理解程序的运行行为。逆向工程主要有两种类型：静态和动态。

静态分析在程序未运行时进行，它是静态的，因为你只是检查程序的结构和逻辑。动态分析在程序运行时进行，我们用它来检查程序的行为。逆向工程技术通常被网络安全专家用于分析恶意软件。许多程序员和游戏开发者也会广泛使用调试器来测试其程序的运行时行为。我的意思是，逆向工程应用无处不在。即使你对破解视频游戏不感兴趣，掌握这项技能对于开发高质量软件仍然极为重要。我要说的是，就像编程一样，没有简单的方法能让你快速精通逆向工程。唯一能做的就是不断反复尝试，你的技能基本上与你所拥有的经验量成正比。话虽如此，还是有一些方法可以加快你的进步。拥有 C 或 C 等底层语言的经验对你将非常有益。如果你精通这些语言，说明你已经对指针引用和地址等内存概念有所了解。其次，花些时间学习汇编代码将非常有价值。

逆向工程的几乎所有方面都会让你接触到汇编代码。你不必成为汇编专家，但看到它时不能害怕。包括我自己在内，大多数人接触逆向工程的首次体验都是通过 Cheat Engine。Cheat Engine 是一款免费开源的程序，专为修改单人游戏而设计。它功能丰富，包含内存扫描器、多个调试器、反汇编器以及更多功能。Cheat Engine 受欢迎的原因是用户可以创建所谓的作弊表，即可在 Cheat Engine 环境中运行的可共享脚本。几乎没有编程经验的用户也可以通过它逆向工程并实现作弊功能，而无需自己编写代码。此外，正如我提到的，这些作弊表是可共享的。然而，你不太会看到经验丰富的作弊开发者用 Cheat Engine 做作弊表。相反，你通常会看到他们只使用 Cheat Engine 的内存扫描器和调试器。

在静态逆向工程方面，你需要一个专用的反汇编器，其中最流行的是 IDA Pro。IDA 是交互式反汇编器 Interactive Disassembler 的缩写，它是一个出色的程序，但它的许可证价格要花费你几千美元。幸运的是，如果你无法获得 IDA Pro 的副本，美国国家安全局 NSA 已经发布了一个免费开源的替代工具叫做 Ghidra。这些程序显然非常不同，但它们的目标是一致的。IDA Pro 和 Ghidra 都主要是反汇编器，它们还附带了调试器，最重要的是还包括反编译器。之前我提到过，当你下载一个视频游戏时，你无法访问其源代码。反编译器是一种能够从反汇编代码中生成 C 语言伪代码的程序。它已经非常接近原始的源。反编译器并非完美，有时生成的伪代码可能完全错误。

因此你不应完全依赖它们，相反，应专注于学习汇编代码，因为只要你能理解，反汇编几乎永远不会让你失望。当你在 IDA 或 Ghidra 中打开一个程序时，它会被分析，反汇编结果将被保存到你磁盘上的数据库中。当你重命名函数和变量时，这些更改会保存到数据库中。这样经过长时间积累，你会逐渐从内到外重建整个程序。不要误以为逆向工程是一个快速的过程，即使是那些看起来轻松做到的人，也需要很长时间。我已经多次提到过调试器，但我还没解释它们到底是什么。调试器是一种程序，允许你在程序执行的不同阶段设置断点。你可以将断点想象成一个压力板或绊线，一旦目标程序执行到断点位置，调试器就会触发一个异常并暂停程序的运行。暂停后，调试器会显示大量信息，例如局部变量的地址、寄存器、函数等等。调试器还会显示局部变量的值，以便你确认程序行为是否正确。

如果你正在寻找调试器，我推荐使用 x64dbg，它是免费且开源的，而且功能非常丰富。对我而言，它就像是动态分析领域的 IDA Pro，只不过它是免费的，而且像本视频中提到的所有前文程序一样，它也支持脚本功能，用户可以扩展其功能。顺便说一句，不要被名字误导，它同时支持六十四位和三十二位平台。好了，现在是时候提一些值得称赞的工具。Cutter 是一个免费开源的逆向工程平台，可与 IDA Pro 或 Ghidra 竞争。它拥有出色的用户界面，它具有极高的可定制性和可扩展性，但该项目相对较新，贡献者不多，依我看来尚不成熟。我非常确信，随着时间的推移，Cutter 会变得越来越好。

接下来，RecastNet 是另一个免费开源的程序，但这个程序有非常特定的用途，它可以将一块内存以多种数据类型显示出来，以便你确定哪一种类型是正确的。当你知道内存块中某个偏移处的数据类型时，Recast 会为你生成一个结构完整、填充恰当的类供你在 C 或 C 应用程序中使用。
