你首先会学习基础知识，比如用于显示信息的打印语句，以及用于存储数值的变量。为了控制程序流程，你会使用 if 语句，并通过 for 或 while 循环来重复执行操作。函数能让你复用代码，而递归则是指函数调用自身的情况。面向对象编程引入了类，用于创建自定义的数据类型。数据结构有助于组织信息。你还会学习不同的算法，比如使用大 O 表示法衡量时间复杂度，以及各种排序算法。第一年结束了，现在进入第二年。离散数学在计算机科学中至关重要。你将从命题逻辑开始学习，即判断真或假的陈述句。为了证明一个陈述是正确的，你需要构建一个证明。集合论专注于研究对象的集合。图论是一个宏大的课题，一个图由通过边连接的顶点组成。模运算也是一种算术，但其结果始终是余数。概率论在计算机科学中也必不可少。你将从概率的基础知识开始学起。

接着你将学习随机变量，它负责将数字分配给随机过程的结果。你将探索各种概率分布，例如二项分布、泊松分布和几何分布。中心极限定理表明，当你提取许多独立同分布变量的样本均值时，它看起来会像正态分布。你最后要学习的是马尔可夫链，其中下一个状态仅取决于当前状态。接下来你将开始学习计算机架构，并从 C 语言编程入门。二进制和十六进制数字被用于表示数字系统中的数据。你还将学习用汇编语言编写代码，研究数字逻辑以了解电路的工作原理，设计一个运行指令的简单处理器，并探索如何组织内存和缓存以提高运行速度。在第三年，你可以拓展领域，选修各种各样的课程。在软件工程中，你会学习用户需求、软件架构和设计模式。你还会练习使用 Git 进行协作，并编写测试以确保代码的可靠性。基本上就是学习真实团队是如何构建和维护软件的。

在计算机安全方面，你会研究漏洞，学习密码学来保护数据，探索 SQL 注入和跨站脚本攻击等外部安全课题，最后以网络安全结束。在算法课上，我们在数据结构的大 O 表示法基础上进行深入，使用它来严谨的分析和对比解决方案。你还学到了分治法、贪婪算法和动态规划等技术，并将它们应用于解决问题。在 AI 领域，你会探索高效寻找方案的搜索算法，学习 AI 智能体通过试错进行学习的强化学习，以及教计算机识别模式的机器学习。
