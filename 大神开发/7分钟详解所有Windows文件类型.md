The EXE format is the most famous and most widely used file type in Windows. EXE has existed in all operating systems made by Microsoft, from DOS to Windows 11. These files run directly by the operating system itself, and most executable files in software installers come in this format, like games, programs, and their setup packages. MSI format is the standard package installer format in Windows. It was introduced with Windows 2000, and it's still one of the most important file types in Windows. This type of file isn't a program itself. It runs through the Windows Installer service to install, repair, or uninstall softwares. Most companies and organizations release their software installation packages in this format. A BAT file is basically a list of instructions that run one after another, and it's usually used to automate simple tasks like opening programs, copying or moving files, or changing system settings. For example, with just a few simple lines of code, you can write a script that creates a new folder every time you run it. All you need to do is save the code inside a text file, change its format to BAT, and run it. The COM format is an old executable file type in Microsoft Windows. It used to run on older Windows systems and 32-bit versions, but it's not supported on modern 64-bit systems anymore. This type of file is actually the simplest kind of executable program, because it runs directly as machine code and is mostly used for very small programs. That's also why COM files can't be larger than 64 kilobytes. VBS files, like BAT files, are scripts that Windows runs line by line. But the difference is that VBS files can do more complex tasks than BAT files. They run through the Windows Script Host and people usually write them manually in Notepad. Both of them do the same thing, but just use a different language to do it. MSP files were added to Windows from Windows 2000. MSP stands for Windows Installer Patch, and is used to update or fix an already installed program. It's not a standalone installer by itself, but applies changes or fixes to software that's already on your computer. CPL files are control panel modules in Windows. When you run one, it opens the specific control panel page it's made for. You can't just make them like simple scripts, such as BAT.或 VBS，因为 CPL 是编译文件，通常用 C 或 C++ 编写。

但你可以在 Windows 系统 32 文件夹中找到它们的例子，双击一个会带你到相关的控制面板部分。CMD 是 Windows 命令提示符格式。在 CMD 文件中，你可以放入多个命令提示符命令，保存它，当你运行该文件时，所有命令将按行执行，Windows 会显示结果。例如，你可以创建一个简单的 CMD 文件，首先显示系统的网络设置，然后 ping DNS。REG 或 REG 文件是用于 Windows 注册表的。注册表是 Windows 的深层和主要控制中心。你可以用它将右键菜单恢复到 Windows 10 的状态，或者让 Windows 11 在安装时忽略某些硬件要求。

REG 文件通常会更改、删除或添加注册表中的值，但你必须小心，因为编辑注册表很棘手，甚至可能损坏你的系统，这就是为什么 REG 文件可能很危险。DLL 文件基本上是程序或游戏需要运行的库，使软件模块化，从而保持程序大小较小。但如果程序需要一个 DLL，而该 DLL 不在你的系统上，程序将无法启动。例如，大多数游戏需要一个 DLL，称为 d3dx9，才能运行。这些 DLL 是 Microsoft DirectX 的一部分，提供现成的 3D 图形和其他基本功能，以使游戏正常运行。链接或 LNK 是 Windows 中的一种文件格式，基本上指向系统中的另一个文件。LNK 文件通常包含目标文件的路径和图标，当你打开它时，它会运行该目标文件。你桌面上的所有图标通常都是 LNK 文件，当然，前提是它们有那个小快捷方式箭头。

要创建链接或快捷方式，你只需右键单击你想要的文件，然后选择“发送到桌面”。这将在你的桌面上创建一个快捷方式，或者你可以轻松右键单击并选择“新建快捷方式”。然后你需要选择你想要快捷方式的文件，为它命名，现在你的快捷方式就准备好了。另一种类似的格式是 URL，不同之处在于 URL 文件指向网站而不是文件，当你打开它们时，它们会带你到该网站。
