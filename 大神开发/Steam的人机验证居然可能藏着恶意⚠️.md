这是一个伪装成电竞平台的病毒网站，千万别被它的外表骗了，它是黑客专门用来投放木马病毒的。网页下面有一个按钮，我们点击之后，它会提示你进行人机验证。这个人机验证的方式和平常的不同，它居然要求你在系统的 PowerShell 当中执行一串代码，今天我们就给它一扒到底，看看这个恶意代码是如何工作的。这里先跟大家科普一下，我们在浏览网页的时候，网页中的元素是被浏览器限定在一个容器之内运行的，在浏览器本身没有漏洞的情况下，病毒再怎么蹦跶也不会感染到系统。但这次的病毒搞了个例外，它要求你绕过浏览器的限制，直接在操作系统终端里面以管理员身份执行一条命令。那么众所周知，Windows 的管理员权限是可以被继承的，使用管理员权限可以通过复制令牌的方式获取超级用户权限，甚至可以通过挂载驱动提升至内核态。

也就是说一旦你执行了那条代码，事情就变得不可控了。回到这个网页上，它提示已经把代码复制到我们的剪贴板中，我们把它粘贴到记事本上，注意到这个代码是一段经过混淆后的 PowerShell 指令，一共可以把它分为五个部分，前面定义了一些字符串变量，其中包括加密用的固定偏移量，加密后的十六进制字符串以及解密密钥。随后通过一个 for 循环语句定义了一个算法，对字符串进行解密，随后将解密出来的明文存入一个变量，最后调用 IEX 指令执行解密出来的明文。我们想要获得明文最简单的办法就是直接去掉这个 IEX，把执行这个变量当中的命令改成以文字的形式输出这个变量的内容。最后我们在 PowerShell 当中执行修改后的代码，就可以拿到第一阶段恶意代码的明文。

继续分析这个明文，我们发现它会生成一个随机的绘画 ID，然后用这个绘画 ID 去访问一个网址，下载一个文件并且从服务器获得一个解密密钥。这里它为了防止杀毒软件检测，还将字符串采用了分段写法，随后将解密后的二级脚本写入一个随机目录，最后执行二级脚本并传入当前的绘画 token。我们随便写一个绘画 ID 去访问一下它的那个 T 的网址，发现它返回了一个字符串，接着用同样的绘画 ID 去访问 download 的网址，发现它下载了一个文件，这个文件是加密的，解密算法在那个 PowerShell 脚本里面，密钥就是服务器返回的 T。

我们现在想要获得这个二级脚本的内容，最简单的办法就是直接修改脚本最后一行，原本是使用 PowerShell 运行这个 PS 一文件，我们把它改成使用记事本显示这个 PS 一文件，最后在 PowerShell 当中运行我们修改后的脚本，这样记事本当中就显示出来了那个二级恶意脚本的内容。不过显然它也是经过混淆的，混淆的方式和刚刚的一级脚本是一致的，我们直接故伎重施，去掉最后面的 IEX，然后执行它，现在我们就得到了它的二级脚本的最终内容。

二级脚本前面定义了黑客服务器的地址并接收传入的绘画 token，然后启动一个全局互斥锁，防止重复运行，自动请求管理员权限，运行完成后立刻删除自己，通过读取注册表获取 Steam 安装路径，进入 Steam 安装目录并植入木马，主动向 Windows Defender 添加多条排除路径，自动下载一个压缩包，随后将其解压至 Steam 安装目录，接着删除所有临时文件销毁证据，并自动创建防火墙规则，放行 Steam 的全部网络流量，最后无论安装成功或者失败，都会向服务器实时传达当前状态。可以说这就是一个专门针对 Steam 玩家设计的木马病毒。我这里给它布置一个陷阱，做一个假的 Steam 安装目录，勾引病毒上钩。

一切就绪后我们直接执行它的恶意脚本，可以看到在脚本运行的过程中网络出现了大量占用，说明脚本正在后台偷偷下载恶意文件。等待脚本运行完成，我们再次打开刚刚的那个钓鱼网站，发现上面提示我们重启电脑，证明此时病毒已经发作完成，我们直接去拜访一下那个假的。Steam安装目录，这一大堆就是病毒释放的文件，这些文件会永久寄生在你的Steam安装目录。它们通过DLL劫持进行加载，可以窃取你的Steam登录凭证，可以控制Steam强制退出登录，诱骗你输入账号密码，并且可以通过篡改前端JS脚本，显示虚假的网页进一步实施诈骗。
