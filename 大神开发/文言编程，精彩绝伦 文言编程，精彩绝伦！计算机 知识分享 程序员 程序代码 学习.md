行啊，咱们得先看看这个文言编程语言大概长得啥样。项目的作者名为黄令东，是CMU的一位大四学生。语言的底层还是转换为Python或者是JS来运行，不过并不是简单的进行关键字中英文替换。我们先来看看这些语法，这个文言语言中一般使用吾有开头来定义变量，比如吾有一数，曰三，名之曰甲。有数五十，名之曰乙。吾有一列，名之曰战。得益于汉字的精炼简洁，绝大部分语法可以控制在四个字。除十以三，所余几何？昔之甲者，今其事矣。如果命名得当，非四字的语法读起来也可以朗朗上口。吾尝观算经之书，方悟正弦之意等等。并且和古汉语一样，标点符号和换行都可以省略。正是因为这些语法充满节奏感，所以很多小伙伴尝试了这个语言后大呼过瘾上头，过瘾呐，过瘾。

不过仅仅是节奏带感，那么这个文言编程语言并不能真正吸引这么多的粉丝，它更重要的魅力在于这些编程的语法也是完全符合文言语法的。黄同学花费了一番功夫，使用自然语言处理技术对语法进行了优化，使得这个语言写出来的程序读起来呢比较流畅自然，能做到见文识义，这确实非常难得。并且开发者还附带了一个在线IDE和几十个写好例程，方便我们体验尝试。还有一个非常炫酷的代码渲染器，可以把代码输出成古汉语书籍样式的矢量图，同时它还可以将生成的SVG文件解析回原始代码。总之啊可以说是很用心了。项目开头的这篇序言更是将黄同学的文学才华展现的淋漓尽致。序言介绍了黄同学创建这个项目的原因，其中用典丰富，句式工整，不仅大量使用历史典故，也穿插了一些编程中的内容。相信各位看到鼠蟹钻鱼或以素称，蛇象洛溪各征文采这句话时都会会心一笑。

在媒体采访中，黄同学就表示自己对文学十分感兴趣。文言编程项目刚发布的时候，他正在读《淮南子》这本书，序言中鬼之所以夜哭，天之所以雨粟就点出自《淮南子》的本经训，不得不说这个项目真是文理两开花呀。而且作者还写出了文言编程语言的教程文档《文言音符》，这个文档当然也是用文言文写的，不过教程中用到的文言文都比较通俗，很容易就能看懂。我遇到的困难就是文档中都是繁体字，刚开始确实不太适应。目前文档一共分为十三个部分，直接看标题就能大概了解每节讲解的内容。比如名义篇主要介绍文言文编程的基本信息，变数篇介绍程序中变量的概念，府库篇介绍模块导入和使用，全部加起来基本包括了流程控制、数据结构、函数、基本面向对象、绘图、异常处理等内容。并且还附带了很多的例程，在最后黄令东同学还单独写了一段文字来介绍当今的炼丹术、深度学习技术。

总的来说这个教程的内容还是比较全面的。那么我也仿照它里面的例程用绘图库画了一个硬币的图案。啊，我画了一个硬币，哎这个都懂我意思吧？不过这个语言的绘图库的调色功能实在太难用了，文言文不能直接设置十六进制的颜色，我只能慢慢蘸水调色，试了半天才弄出来个差不多的粉红。这里再吹一下黄同学的命名，实在是很有意境啊，你看这些方法，落笔、运笔、提笔、蘸水、调色、背纸、裱画，写程序的时候真的感觉像是在画画一样。那么我们继续聊一聊这个文言编程语言的在线IDE，这个IDE在项目刚发布的时候就有，只不过那会儿功能不完整。不过现在这个IDE不仅已经开源，还附带很多例程，它的代码高亮、语法提示、报错信息都。都已经比较完善了，还能直观看到编译后的 JS 代码，并且可以使用 iframe 把它嵌入到你的网站里，通过查询字符串来配置它的功能。

在线 IDE 可以自由选择主题配色、输出形式，并且除了 JS 还支持编译到 Python 和 Ruby，但是在线 IDE 中目前只有编译到 JS 才可以运行。还可以直接把你的代码渲染成之前提到的印刷样式的矢量图，总的来说相比于刚发布的时候，它的功能提升还是很大的。除了在线的 IDE，还有开发者专门为 VS Code、Sublime 等编辑器开发了对应的文言编程语言的插件。当然一门语言想要有良好的生态，除了必备的官方入门文档和开发工具，还得有丰富的第三方扩展包。文言编程语言自然也不能落后，并且黄同学为它量身打造了包管理器文渊阁，这个名字也是很到位了。

文渊阁可以直接使用 npm 命令安装，使用起来非常简单，按照所给的例子执行后就能安装名为子曰的包，完成后包会被下载到藏书楼子曰这一路径下，藏书楼目录类似于 JS 的 load modules。安装完成之后就是导入了，使用无常观子曰直书方物子曰之义的格式的代码就可以导入。目前文渊阁有如下第三方扩展，甚至你还可以在浏览器中使用文渊阁，也支持发布你自己开发的模块。这样一看文言编程语言确实设计的有模有样，虽然目前发布的模块不多，但是这抵挡不了天朝程序员天马行空的想象力。前面我们提到计算机科学中经常把深度学习技术自嘲成炼丹术，这下再碰上文言文编程语言，那必须好好结合一下我们的古老文化，给整个炼丹炉的模块出来。确实就有小伙伴在一秀里面贴出一段代码，这炼丹备料丹炉还真是都有，逻辑非常完整啊。

虽然目前没有火炬心法这个模块，说不定真的有一天能把 numpy 等工具包搬到文言文语言上，那个时候就真的能开炉炼丹了。不过各位小伙伴的想象力还不仅限于此，有老铁看到这个文言编程语言之后灵光一闪，脑洞大开，整出来一门东北方言编程语言。根据作者描述，东北语言基于 Python 三，采用了业界领先的吹牛逼驱动开发方式，具有极高的语际比，语法非常魔性啊，看完附带的历程确实人都要笑傻了呀。不过这个作者可是一本正经，不仅整出了解释器，还写了一套教程文档，并且居然还附带有一首宣传歌曲东北 style。编程第一步哎，对世界得有礼貌，要想发生别的不行，咱们得说唠唠，说完唠唠第二件事还得要打冒号，要唠的事咱都得放进那双引号，完了打上句号，我也是非常重要，程序看见句号就知道操作完了，要不带见句号还有了。
