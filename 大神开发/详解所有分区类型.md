MBR。当你按下计算机的电源按钮时，系统的固件，称为 BIOS 或 UEFI，首先检查所有组件是否正常工作。这个过程称为 POST。之后，它会在系统中的存储设备上搜索一组特殊的指令。这组指令称为引导加载程序。主要有两种不同的方式可以将此引导加载程序存储在存储设备上。一个是 MBR，另一个是 GPT。但在此之前，让我们了解它的来源。每个操作系统都有自己的引导加载程序。在安装过程中，操作系统会将其放置在存储设备的特定位置。现在，此位置取决于系统使用的固件类型，无论是 BIOS 还是 UEFI。如果您的系统使用 BIOS 固件，则在安装操作系统期间，引导加载程序将存储在存储设备的第一个扇区。此引导加载程序称为 MBR 或主引导记录，此类分区称为 MBR 分区。

它只占用 512 字节，安装后，BIOS 将仅在此扇区中搜索引导加载程序。MBR 的问题是它与 BIOS 固件绑定。而 BIOS 只支持最大 2TB 的磁盘大小。这意味着，如果您尝试使用 BIOS 在 3TB 硬盘上安装 Windows，您可能会看到错误，说 Windows 无法安装在此卷上。即使安装以某种方式成功，系统也只能识别驱动器的 2TB，其余空间将无法使用。同样，如果您尝试创建超过支持限制的分区，系统将显示错误，表明分区限制已超出。此外，MBR 只存储其关键数据的一个副本，如果它损坏，则系统将无法启动。这清楚地表明 BIOS 对于现代系统来说是多么有限和过时。GPT。另一方面，像 UEFI 这样的现代固件使用 GPT 分区系统。

在这种系统中，而不是一个微小的引导加载程序，紧接在前 512 字节之后的空间用于存储一个称为 EFI 系统分区的特殊分区的地址。我稍后将解释 EFI 分区是什么。UEFI 支持非常大的存储设备，远远超过旧的 2TB 限制，并默认支持单个驱动器上的 128 个分区。最大分区大小可达到惊人的 18EB。由于这些功能，GPT 比 MBR 更灵活、更快、更可靠，适用于现代系统。最好的是 GPT 是一个冗余系统。它在磁盘的末尾存储额外的分区数据副本，以便在数据损坏时恢复系统。EFI 系统分区或 ESP 是现代系统中用于存储引导文件的特殊分区。在 GPT 驱动器上安装操作系统时，此分区会自动创建。它通常没有驱动器字母，并对用户隐藏。当系统启动时，固件首先读取磁盘上的分区表，然后将其指向此 EFI 分区。

从那里，它加载所需的引导文件以启动操作系统。此分区还可以包含多个操作系统的引导文件，这就是为什么它用于双引导设置。它通常很小，并且格式化为 FAT32 文件系统，因此固件可以轻松读取它。交换分区。把你的电脑内存想象成一个物理书桌，你在那里做所有工作。有时，你打开太多书籍和文件夹，导致你的书桌完全装满。当你的书桌（RAM）用完空间时，计算机不会崩溃。相反，它会将您有一段时间没有碰过的文件夹移动到一个特殊的溢出区域，称为交换分区。这会为你。

Because the swap partition is on your hard drive or SSD rather than in fast memory chips, it is much slower than your actual RAM. If your computer is using a lot of swap space, you might notice it feels a bit sluggish or laggy. Swap partition is mainly created and used on Linux systems. Recovery partition. Think of the recovery partition as a spare tire hidden in the trunk of your car. You don't use it every day, but it's a lifesaver when you get a flat tire. Instead of regular photos or movies, this partition holds a special "emergency version" of Windows called the Recovery Environment. It contains troubleshooting tools that can scan for errors, undo recent updates, or even reset your whole computer back to the day you bought it. It lives in its own "room" so that even if your main Windows, the C drive, gets a virus or a major system error, the recovery tools stay safe and untouched. If Windows fails to start several times in a row, the computer automatically pulls the "emergency handle" and boots into this partition instead. From there, it asks you if you want to try an automatic repair or reset this PC. Primary partition. A primary partition is the main section of a storage drive where an operating system can be installed and booted from. In older MBR-based systems, a disk can have up to four primary partitions. Each of these partitions can hold an operating system or be used for storage. Out of these, one partition is usually marked as active. This is the partition that contains the second stage of MBR bootloader, which the system uses to start the operating system. Primary partitions are simple and direct. The system can access them easily without any additional structure. However, the limitation is the number. Since MBR only allows four primary partitions, this restricts how the disk can be divided. Extended partition. An extended partition is a special type of partition created to overcome the limitation of having only four primary partitions in MBR. Instead of storing data directly, an extended partition acts like a container. It holds multiple smaller partitions inside it, called logical partitions. This allows the system to go beyond the four-partition limit imposed by MBR. However, the extended partition itself cannot be used to install an operating system directly. It only serves as a structure to organize additional partition. Moreover, extended partition replaces one of the four primary partitions, so you can only have three primary partitions and one extended partition on a drive. Logical partition. A logical partition is a partition created inside an extended partition. Unlike primary partitions, logical partitions are not directly recognized as independent bootable partitions by the system. However, they can still be used to store data or even install an operating system depending on the setup. The main advantage is flexibility. You can create multiple logical partitions within a single extended partition, allowing better organization of data. MSR partition. Or Microsoft Reserved Partition, is a small hidden partition created automatically on drives used by modern Windows systems. Its sole purpose is to reserve space for system use. For example, if Windows ever needs to perform a special disk operation, like converting a basic disk to a dynamic disk, it shrinks the MSR and uses that tiny bit of reclaimed space to store the new management data. You usually won't see or interact with this partition, but it plays an important role behind the scenes. Without it, certain disk management operations in Windows may not work properly.
