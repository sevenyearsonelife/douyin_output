本期视频带大家手把手安装 DeepSeek - Harness。先决步骤是安装 Node.js。搜索 Node.js。点第一个。点下面的 Download。点左边的这个 Windows Installer 下载并安装。主包这里因为已经配好了环境就跳过了，下载完打开之后一路点下一步就行了。接下来是验证 Node.js 是否正确安装，按 Win 加 R，输入 cmd，按回车。把后面两个命令选中，按 Ctrl 加 C 复制过来，粘贴到刚才的黑框里，然后按回车执行。如果显示了 V A X Y Z Z 这样的格式，说明安装正确。如果报错了就重新安装一遍。接下来安装 DeepSeek - Harness 的本体。搜索 DeepSeek。点进去。点右上角的中文。下拉找到 DeepSeek - Harness，点进去。

这里就是我们用来安装的命令了。我们把它复制一下。按 Win 加 R，输入 cmd，按回车。把刚才的命令粘贴上去。挪动光标，在 npm 和 at 符号中间加入杠杠 web-oses 并用空格隔开，按回车执行。提示你输入 y，输入 y 然后按回车。这里之后就是漫长的下载，可能要很久很久，有的大文件能卡几分钟，这个时候可以去喝杯茶。然后长按点赞键给本视频三连。三连连过后 DeepSeek - Harness 就准备好了。这个时候会提示你有一个 HTTP 的链接，按住 Ctrl，然后鼠标左击打开它，或者复制到地址栏打开。阅读一下提示。然后点 continue。接下来需要 API - Key，我们回到 DeepSeek 的网站打开 API 开放平台，用你的手机账号登录它。我这里是已经用过一阵子的账号。

第一次用的账号要给梁老师充值报名，如果你不滥用的话十块钱够用很久。在确保你账户余额足够之后，点左边的 API - Keys，再点 Create New API - Key，取一个好记的名字。复制你的 API - Key。粘贴回到刚才的页面。工作以 workspace 为单位，最好一个项目用一个单独的一个文件夹。右键新建文件夹，然后取一个好记的名字，点选择文件夹。创建好之后配置一下设置。上面选择工作模式，这里选择创造模式，右下选择模型，选择 V4 - Flash，模式任意。然后这里选择 workspace write，可以限制它的修改仅限于 workspace。刚才的命令行黑框是不可以中途关闭的。接下来测试一下。让它自我介绍。最后让我们来制作一个桌面快捷方式。右击空白位置。选新建杠快捷方式。

复制刚才用来安装的命令，它也是打开 DeepSeek - Harness 的命令。粘贴，同样是加上空格隔开的杠杠 web.localhost。点下一步。给它取个名字，比如 DeepSeek - Harness 或者 DH。在刚才的黑框已经退出之后，双击打开刚才创建的快捷方式。同样是显示 web http 后面跟一串。退出之后回到 DeepSeek 的官网下拉打开 API 文档，右击左上角的黑色鲸鱼 logo。将图像另存为。选一个你将来能找到的路径。搜索 png 转 ico。打开网站。点选择文件，选刚才创建的文件。点开始转换。转换完毕之后点下载。点文件链接。右击灰色鲸鱼，另存为一个能找到的位置。保存完毕后回到桌面右击你创建的快捷方式，点显示更多选项，点属性，点更改图标。点浏览。选择刚才保存的 ico 文件。

点确定。再点确定。退出之前的黑框。双击打开快捷方式。按住 Ctrl，然后鼠标左键 http 链接，这是以后启动 DeepSeek - Harness 的流程。至此，我们已经完成了安装流程。
