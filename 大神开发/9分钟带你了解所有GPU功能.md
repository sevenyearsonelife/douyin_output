光线追踪。光线追踪是一种图形功能，能让光照和反射效果更加逼真。其工作原理是不再简单的为物体添加光照，而是让 GPU 模拟光线从光源出发，照射到表面并形成精确反射或阴影的过程。为了更清楚的说明，我们来对比这两张图像。没有光线追踪时，反射效果往往不准确。虽然这里有光源，但地面上几乎看不到任何反射。而且轮胎上的反射也不合理，因为光线来自左侧，反射却出现在右侧。但开启光线追踪后，不仅水洼清晰反射出光源，轮胎的反射也出现在正确的一侧。尽管效果出色，但这不意味着必须始终使用光线追踪，因为光线追踪主要适用于反射表面周围有光源的场景，比如玻璃、水面或类似物体。但如果游戏场景多为开阔区域，像这片没有反射表面的草地，即使开启光线追踪，差异也很小。此外，使用光线追踪时帧率会下降，因为该功能需要大量 GPU 算力和显存。

在竞技游戏中情况更糟，没有光线追踪时还能获得数百帧。但开启光线追踪后，帧率会大幅下降。路径追踪。路径追踪与光线追踪类似，但更为先进。光线追踪仅处理特定区域的光源和反射效果。但这里有些区域尽管有明亮的霓虹灯，却未受影响。而路径追踪会计算整个场景的光照，让整体画面更加逼真。因此某些场景几乎与现实无异，难以分辨是渲染画面还是真实拍摄。但这也使得路径追踪负荷更重，帧率会显著降低。即使与常规光线追踪相比也是如此。和之前一样，如果场景光照均衡，光线追踪与路径追踪的差异可能也很小。另一方面，在像这样拥有大量光源和反射材质的场景中，路径追踪有时会使反射过强，而此处的光线追踪效果更好，既不平淡也不过度反射。由于这些原因，更多人倾向于使用光线追踪而非路径追踪。DLSS。

DLSS 全称为深度学习超级采样，是 Nvidia 推出的功能，可减轻 GPU 工作负荷。如果我们经常使用光线追踪或高分辨率游戏，这个功能特别有用。例如以四 K 分辨率游戏时，GPU 每帧需要渲染超过八百万像素。这对硬件要求非常高，与其强行渲染，我们可以使用 DLSS 功能。现在 GPU 只需以一千零八十 P 渲染游戏，其余部分由 DLSS 处理。由于 GPU 只需渲染较低分辨率，其负载也大幅减轻。因此，即使大型游戏原生帧率仅约三十帧，开启 DLSS 时仍能显著提升帧率，使游戏体验更流畅。但由于依赖 AI 重建技术，DLSS 有时会出现细微视觉伪影或小故障。正因如此，有些人不喜欢使用它，更倾向于原生分辨率。FSR。FSR 代表 FidelityFX 超级分辨率，是 AMD 版本的画面增强技术。

与 DLSS 类似，真画面先以低分辨率渲染，再升级到高分辨率以提升性能。但在画质方面，FSR 有时看起来不如 DLSS 清晰扎实。但优点是与仅限 Nvidia 显卡的 DLSS 不同，FSR 同时兼容 AMD 显卡，这使其成为绝佳替代方案，因为某些情况下 DLSS 会出现重影。或模糊等视觉问题，尤其在特定驱动更新后。帧生成，帧生成功能可提升大型游戏的帧率和运动流畅度。通常 GPU 会逐帧渲染，但开启帧生成后，系统会在真实帧之间插入人工帧。因此屏幕上显示的总帧数会大幅增加。使用帧生成让画面更流畅，但尽管更流畅，帧生成也可能增加延迟或输入滞后。实际对比这两张图的响应速度时，原生渲染中子弹已抵达目标并弹开。但开启帧生成后，子弹仍在飞行，尚未击中目标。

因此帧生成不适用于快节奏竞技游戏，它更适合 cinematic triple A 游戏，这类游戏更注重画面流畅度而非反应速度。不仅如此，有些人更偏爱原生渲染，因其画面扎实且图像精度更高，但如帧生成画面所示，有时会出现扭曲或重影等视觉问题。动态分辨率，动态分辨率缩放功能有助于在高负载场景中保持稳定帧率。假设我们正以稳定的六十帧进行游戏，通常当出现爆炸或大型粒子特效等重负载视觉效果时，GPU 需要更努力工作，帧率会突然下降，待场景负载减轻后恢复正常。但开启动态分辨率后，游戏会在高负载时自动降低分辨率，从而保持帧率稳定。当重负载特效消失后，分辨率会恢复至原始水平。HDR，HDR 代表高动态范围，这项功能可提升场景亮度和色彩深度。

没有 HDR 的图像会显得平淡，但开启 HDR 后，色彩更鲜艳饱满，连背景最细微之处也清晰可见。这非常实用，因为当色彩层次分明时，更容易发现阴影或雾气中的物体和敌人。但如果没有 HDR，我们几乎看不清物体形状，因为所有东西都混在一起了。但请记住，你的电视或显示器也需要支持 HDR，否则你在屏幕上就看不到完整的 HDR 效果。显示同步，显示同步是处理画面撕裂的技术。当 GPU 生成帧率与显示器刷新率不同步时，就会出现画面撕裂。当新帧在显示器完成显示前帧之前发送时，两个不同帧的部分内容会同时出现在屏幕上。为解决这种撕裂问题，我们有了垂直同步技术，即 V-Sync，它可以强制 GPU 匹配显示器的刷新率，但这样做也会增加输入延迟，因为 GPU 被强制跟随显示器刷新率。

为改善这种情况，NVIDIA 推出了 G-Sync，AMD 则推出了 FreeSync。与 V-Sync 强制 GPU 不同，这些技术让显示器动态同步刷新率来匹配 GPU 输出。这样既能处理画面撕裂，又能比传统 V-Sync 保持更低的输入延迟。但记住，要使用 G-Sync 或 FreeSync，你还需要兼容这些功能的显示器。所以我也标注了一些推荐的兼容显示器供你参考。抗锯齿，抗锯齿是让游戏边缘变得平滑的功能。在视频游戏中，许多物体边缘会显得锯齿状，这种效果称为锯齿，是因为游戏是通过像素渲染的。如果你坐的离屏幕稍远，可能不会注意到这些锯齿边缘，但由于大多数人玩游戏时坐的较近，那些边缘变得明显，让游戏画面显得很生硬。所以需要开启抗锯齿，让边缘看起来干净平滑。

各项异性过滤，当场景中出现长路或广阔地面时，只有离你近的物体看起来清晰，远处的物体会开始变得模糊不清。这很糟糕，因为。因为很多游戏需要从这个角度观看，比如赛车或大型开放世界游戏。所以需要开启各向异性过滤，让 GPU 即使处理远处拉伸的纹理也能保持清晰。纹理质量。纹理是包裹在物体表面的图像，比如墙上的裂缝或角色的服装。需要说明的是，纹理质量与分辨率是不同的。分辨率改变的是像素数量，比如一千零八十 P 或四 K，影响的是整个图像的清晰度。而纹理质量只改变物体表面的细节层次，不影响整个图像。在纹理细节方面，大多数低质量纹理甚至不会显示任何图案，就像壳上的包装。设为中等时开始出现一些图案，尽管看起来仍然模糊。在高质量纹理下，编织面料的细节变得清晰可见，更加真实。但如果我们设为超高，实际上与高质量的差异非常小。

这就是为什么大多数人，包括我自己，都选择高质量而非超高，尤其因为我们反正也看不出区别，而且它对 GPU 的负担没那么重了。NVENC 是 NVIDIA 显卡内置的硬件视频编码器，对直播和录制很有用。通常当你直播或录制时，是由 CPU 来处理编码工作，但这很不好，因为编码是项高负荷任务，可能会降低你的帧率。但使用 NVENC 时，编码会改由 GPU 内的专用芯片处理，这样 CPU 占用率保持较低，帧率下降也最小化。
