给大家推荐一款强大 Linux 监控工具，可以实时可视化监控性能指标，监控的指标啊也非常全面。这个工具叫 netdata，是一款轻量级的 Linux 系统可视化监控工具，即开即用，使用非常简单，安装上就可以去使用，也不需要过多的配置。呃这个工具在 Linux 上默认是没有安装的，我们需要先把它给装安装一下，使用 yum install netdata 进行一个安装。安装上之后，一样是直接就可以去启动它了。嗯但是我们在启动之前，先修改一下它的监听地址，因为它默认监听的是本地，如果你不修改的话，将无法在浏览器上直接访问它。所以我们修改一下 netdata 它的配置文件，将监听地址改为四个零。在 bind to 这里，将 localhost 改为四个零。好，改完之后呢启动一下这个服务。

启动完成之后，它监听在一九九九这个端口。可以看到端口进行监听，我们可以通过这个端口来访问它的 web 管理系统了。输入这台服务器的 IP 地址和幺九九九端口，然后回车来访问它。现在就看到了 netdata 这个页面，等待片刻，现在 netdata 已经展示出来了。可以看到在首页有个系统的概览，这里面呢呈现出来了硬盘、CPU、内存、网络资源使用情况，呃这里可以一目了然的观察到 Linux 系统的核心指标，它的当前的使用率有没有瓶颈，啊使用率哪个有没有过高，一眼就能看出来。呃在右侧这里可以分别的去查看它监控的这些指标。

系统概览这里呢你可以直接点击 CPU，它会切到 CPU 这里，它是一个趋势图的形式给你展示当前的使用率，呃剩余了多少，啊用户态、内核态分别使用多少，啊包括系统负载、硬盘的使用情况，硬盘 I/O 读写 L 情况，然后包括硬盘分区的挂载的情况，然后网络接口流量的一个情况，还有一些系统服务的一些情况，可以帮你了解到当前系统中啊运行了哪些服务。这里先就介绍这么多，大家可以安装体验一下，对于单台 Linux 服务器的监控啊非常的方便，而且监控的指标呢非常直观全面，啊值得一用。好，感谢您的观看，下次再见。
