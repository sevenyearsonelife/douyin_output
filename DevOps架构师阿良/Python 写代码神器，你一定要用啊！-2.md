如果你在学习 Python，那这个工具一定要用。之前做笔记都是一边写代码，一边写文档，再编再写，现在有了它都不一样了。图文代码混编，全在一个文档里，边看边写边执行，非常方便。这个工具叫 Jupyter，使用之前你需要在你的 Python 环境里使用 pip install 安装 Jupyter。我这里已经提前安装过，我再执行一下呢，它会检查有没有更新。安装完成之后执行 jupyter notebook 启动它。好，这里已经启动，这里给你输出了访问 Jupyter 的地址，复制这个链接到浏览器中。对，你没有看错，它是基于浏览器进行去实现的。在这里会呈现出它的工作目录啊，你可以先创建一个目录，将你写的笔记都放到这个目录下，方便去管理。比如创建一个这个目录。

ipynb 创建目录，然后进入这个目录里面，你可以继续再创建一个基于 Python 的文档。好，创建完成之后呢，它会再给你打开新的窗口，在这个窗口里你第一时间先修改一下这个文档的名字，比如叫 py1。这里啊就是可以直接写 Python 代码，例如输一个 print hello world。点击执行，看，就直接给你输出这个结果了。如果你在这里呢写的是涉及到图形渲染，也会直接就给你渲染出来。也可以在这里呢直接去写 Markdown，例如测试，好，直接就可以在这去写，进行去切换，然后还可以继续的在下一行再写，也可以继续在它的之上去添加，比如再添加执行个代码。等等，一二三，然后再执行，哎，就直接执行了。你可以在这写任意的代码，包括是一个代码块，多行都可以执行的。好，例如我在这写个 for 循环。

print 打印一下，一样执行啊，就会将这个结果呢都给你呈现出来。当你写完或练习完之后，将这文档进行去保存，它就会保存一个 Jupyter 的文档在你刚才创建的那个目录下。你也可以将它下载到本地，你点击这个下载，就会直接将 Jupyter 的这个文档下载到本地了，在别的电脑上就可以使用 Jupyter 进去打开它。也可以让它导出其他文件格式，像 PDF、Markdown，点击 Markdown，它就直接给你下载到本地。用 Jupyter 去学习 Python 还是非常方便的，如果你还没有用，赶紧用起来吧，等你解锁更多的知识。
