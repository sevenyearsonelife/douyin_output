Prometheus 赶紧用起来吧，监控 Linux 系统是真方便。Prometheus 是目前使用最为广泛的一款企业级监控系统，可轻松监控上千台 Linux 的服务器，是每一位 Linux 运维工程师必备的技能。这是一台 Docker 主机，在上面创建一个网络和创建 Prometheus 容器。Prometheus 容器已经运行，打开浏览器访问这台 Docker 主机的九零九零端口，将访问 Prometheus。这就是 Prometheus 的首页，可用于 Prometheus 的基本的管理和查看。像 Alert 这里可以查看告警规则，像这里可以执行 PrometheusQL 来去查询里面的数据。在这里可以去查看监控目标，就是监控了哪台服务器。

在这里也可以查看 Prometheus 配置，可以看到 Prometheus 的 Dashboard 还是比较简单的，只提供了一些基本的管理和查看，很难满足企业对可视化这一块的一个需求。所以企业在使用 Prometheus 的时候啊，通常会与 Grafana 结合一块使用，形成一个完整的可视化监控方案。使用 Docker 创建一个 Grafana，查看容器状态。容器已经运行，打开浏览器访问这台主机的三千端口，访问 Grafana。这就到了 Grafana 登录页面，输入默认用户名 admin，默认密码也是 admin，点击登录。初次登录会让你设置一个新的密码，我们设置一下新的密码。提交，这就进入了 Grafana 的首页。

Prometheus 和 Grafana 呢，它是两套系统，也是两家不同公司开源的，所以还需要让它们给集成起来才能一块去使用。将 Prometheus 添加为 Grafana 的数据源，点击 Data Source 这里，第一个就是 Prometheus，添加它为数据源。除了 Prometheus 呢，还支持很多的一些存储类的数据库，比如 MySQL、InfluxDB 啊等等，支持数据源是非常的丰富。选择第一个 Prometheus，然后在这里输入 Prometheus 容器内部的访问地址，Prometheus 九零九零端口。

好，然后点击保存，保存完成之后，在数据源这里就能看到刚才添加了这个 Prometheus，好，这样就完成了 Prometheus 与 Grafana 的一个集成，下一步就可以基于 Prometheus 里面的数据进行可视化展示，使用 Grafana 将展示出非常炫酷的图表。现在看看如何将一台 Linux 的服务器给监控起来。其二这台服务器是搭建的 Prometheus 监控系统，其三是我们要监控起来的这台 Linux 的服务器，这需要在要监控的 Linux 的服务器上安装一个 Agent，叫 Node Exporter。这个 Agent 呢用于采集和暴露系统性能数据，让 Prometheus 好去采集。那么安装这个 Node Exporter 呢也是有多种方式，例如 Docker、二进制。

如果监控目标服务器它是一台 Docker 主机的话，你使用 Docker 去安装这个 Node Exporter 还是比较方便的。如果监控目标没有 Docker，我建议使用二进制，啊，相比于直接你还要安装一个 Docker 再创建容器来的会更方便一点。我这里呢使用二进制来安装 Node Exporter，啊，这个 Node Exporter 是在 Prometheus 的官网进去下载的，啊，下载好之后上传到监控目标服务器，将它进行去解压。解压之后将这个目录呢移动呢我们要安装这个目录下，比如 Exporter。使用 systemd 来管理这个 Node Exporter 程序，为它创建一个服务文件。好，创建完成之后就可以。启动 node-exporter。然后设置开机启动。

好，那么 node-exporter 启动之后啊，它会监听到本机的九幺零零端口，你可以访问这台主机的九幺零零端口，看它有没有采集到系统性能数据。访问它九幺零零端口 metrics，好，可以看到有输出，这些就是它采集的一些指标，暴露给 Prometheus 的。七三这台 Linux 的服务器呢已经安装好了 node-exporter，要想加入 Prometheus 呢这还不够，还需要在 Prometheus 的配置文件里将这台服务器呢添加进来。我们 Prometheus 呢是使用 Docker 进行安装了，所以要进入到 Docker 容器里面来。然后打开它的配置文件。

在下面 scrape config 这个配置里面去添加被监控端，job name 是相当于是一个分组，起了一个名字，所以我们要定义一个 job name。例如 linux server。然后再指定 static config 来指定监控目标，在 target 这里面呢，这是一个数组，在这里面可以以逗号分割添加多台服务器，幺九二点幺六八点一点七三，九幺零零。如果第二台在后面加个逗号继续写就可以了，让 Prometheus 呢去采集它，保存。kill -HUP 一来重载一下 Prometheus 的配置文件，使之生效。

好，再打开 Prometheus 的 dashboard，在 status target 这里呢就能看到我们刚添加的 linux-杠 server 这个 job，下面呢有一个监控目标，就是七三这台服务器。最后一步就是在 Grafana 这里呢进行可视化展示监控的这台 Linux 服务器的一些性能指标，在 create 这里进行 import 导入，导入仪表盘，一二六三三，改个名字，linux 监控，选择 Prometheus，点击导入，好，这就呈现出来了。这个仪表盘来自于 Grafana 它的共享库里面，直接输入 ID 呢它就会自动给加载进来，这个仪表盘并且是针对于 node-exporter 这些数据呢做了相关的定制化制作，所以是非常的炫酷。

我们可以选择一个就近的五分钟，可以看到这些仪表盘的数据呢都已经有了，都已经采集出来了。啊，通过这个仪表盘都可以直观的了解主机的性能信息，包括运行时间、系统负载、内存、硬盘、CPU、网络等等这一些的使用情况，非常的全面，非常直观，有助于了解主机的运行状态，及时发现潜在的问题。如果你们公司还没有使用 Prometheus 监控 Linux 服务器，建议大家赶紧行动起来。
