Linux 网络故障排查必须要懂得五个命令。第一个，ping，ping 用于去测试与目标主机网络是否链接畅通，以及测量往返时间，判断网络质量的好坏。例如 ping 百度服务器，这里发出了 ping 得到了一个响应，说明这个网络连接是正常的。通过这个时间啊可以判断出与它的网络质量，如果要是几百毫秒，可能就说明这个网络质量啊不是很好。第二个，traceroute，用于去追踪本机到目标主机网络的路径，以及网络节点的延迟。呃，当需要了解网络数据包的传输路径，就会用到这个命令。假设我们追踪一下到百度这个域名，可以看到会经过我上层路由，再到互联网中的路由节点，这里呢都会给你呈现出来，及每个节点呢它的一个响应时间。第三个命令，nslookup，用于域名解析查询。

当你需要了解域名解析是不是正常，或者是想了解这个域名解析的具体的 IP，可以使用它呢来做测试。比如百度服务器，这给你解析出来百度服务器 IPv4 和 IPv6 对应的两个域名和它的 IP 地址。第四个命令，ip route，来去查看本机路由表，看一下本机的路由规则配置是不是正确。第五个命令，telnet，用于建立与目标主机的链接，常用于去测试判断目标主机上的服务端口是否打开。假设 telnet 一下百度服务器的八零端口，啊，有这样的一个提示，说明对方的八零端口已经打开。当与目标服务器的端口建立连接成功，就能反映出与目标服务器的网络是畅通的，它的端口也都是访问正常的。以上就是 Linux 网络故障排查要用到的几个命令，都是必须要掌握的。
