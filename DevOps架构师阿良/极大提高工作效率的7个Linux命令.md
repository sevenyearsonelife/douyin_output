极大提高工作效率的七个利用的命令。第一个，快速查找文件路径。假设有一个文件你找不着了，不知清楚它在哪路径下，你就可以使用 find 命令，跟上目录，例如 etc，我要查找 nginx 的配置文件。指定名称，nginx.conf，这样就快速的把 nginx.conf 这个文件找着了。如果你没有记得清文件完整的名称，也可以使用通配符啊，非常的方便。第二个，从标准输入中执行命令。例如像刚才我们查到这个文件，你也可以通过 xargs 这个命令来对查到的文件再它的处理。这个命令呢有个参数是 -i，它会将前面查出的文件以标准输入的方式输入到这个命令中，然后通过花括号作为占位符。例如我查看这个文件内容，你可以使用 cat 后跟花括号，这个花括号呢它就表示前面 nginx.conf，好，这样呢它就会把这个文件呢给你打印出来了。

你还可以在这里呢执行任何命令，例如执行 rm 将这个文件删除，例如做一个 sed 的替换，都是可以在这里进行去完成的，非常方便。第三个，查看文件中包含关键字的行。使用这个 grep 命令可以去查看文件中啊关键字所在的行。例如我想查看 ssh 配置文件中启用 dns 那个参数是否启用了，你可以通过 use dns。这样它就会将该关键字的行给你列出来啊，这个呢是已经启用了。第五个，免交互修改文件。通常我们都是使用 vim 打开一个文件编辑再保存，如果你不想执行这么一个操作，那你可以通过 sed 命令实现免交互操作。假设我将 ssh 配置文件的 dns 那个参数再给注释上，我们就可以使用 use dns yes，通过 sed 进行替换。

ssh 啊，好，你这么一执行，它就会将这个文件中呢给替换，但是呢它不会写到这个文件中，如果你要想写入的话，必须要加一个 -i，好，这样就可以了，然后你再可以 grep 一下 dns。看一下有没有修改成功，可以看到呢已经完成了修改。第六个，文本排序。假设有个 a.txt 的文件，里面呢有一些数字，这些数字并没有进行去排序。现在我希望将这些数字啊进行去排排序输出，那我们可以使用这个 sort 命令进行直接去排序，再加个 -n 参数，根据数字排序，这样就会从小到大进行排序。如果你要想从大到小，再加个 -r 就可以了，这样就完成了文本的一个排序。第七个，免交互生成文件。如果你希望将一块文本免交互写到一个文件里面，我们可以通过 cat 加 -uf 来去实现。

这里的 -uf 就表示从当前行开始去写入，写入到假设 a.txt 这文本中，回车，在这里呢你就可以写入任何的内容，比如 hello 阿良，一二三四五六，然后再输入 -uf 结束，那刚写的那些内容呢就会写到这个文件中。那这里的意思就是会将 -uf 这里面内容传递给 cat。cut 呢再追加到一 a 点 tit 这个文件中，来完成免交互写入。那通常呢我们在写脚本去生成一个文件都会使用这种方式，非常的方便。以上七个命令的命令将能极大的提高你的工作效率，希望大家一定把这些命令搞熟了，在工作中啊都是经常用的。
