除了四零四，其余 HTTP 状态码百分之八十以上的人都不知道。其实很简单，三开头的是运维的锅，四开头的是前端的锅，五开头的是开发的锅。你别不信，来一块看一下。一和二开头的这个就不用看了，就是请求正常，没问题。三开头的一般是表示客户端呢需要进行额外的操作来完成请求。常见的状态码有，三零幺表示请求的资源被永久移动到新地址，这主要做的目的是告诉用户和搜索引擎，我们这个地址发生变化了，以后就要用这个新的。三零二状态码表示请求资源呢临时的移动到新地址，也就是说后面我还可能用之前的。三零三来表示请求的资源呢已经被重定向到另外一个地址，就是浏览器呢它还会再发送一次 GET 请求，那无论你刚开始请求的是 GET 还是 POST，它都会发送 GET 请求再请求一次。三零四表示请求的资源没有被修改，使用了本地的缓存。

四开头的状态码表示客户端请求这里有问题，常见的状态码有四百，一般来表示客户端发送的请求有错误，服务器无法去理解这个请求。四零幺客户端它没有提供身份验证，或者说提供的身份是有错误的。四零三服务器它处理了这个请求，但是它拒绝了，这可能是因为用户他无法访问这个资源，那也可能是该 Web 服务它没有权限来访问对应的文件或者目录。四零四那这个大家都知道，服务端呢就是找不到请求的资源，一般就是没有页面。四零五就是该资源呢不能使用这个方法，比如说这个资源只能使用 GET，而你使用了 POST，POST 它是不支持的，就会报四零五。五开头的表示是服务端的问题，常见的状态码有五百，服务端它遇到了意外的错误，无法完成请求，一般是程序这块代码逻辑有问题。

五零二服务器它当它作为网关或者代理的时候，通常才会报五零二状态码，也就是它从上游服务器收到了无效的响应，上游服务器呢没给它正确的响应而导致的。五零三就是服务端无法处理当前请求，那可能是你的服务器负载过高，或者是服务挂掉了。五零四服务器当它作为网关或者代理的时候，就是在没有规定时间从上游服务器获取响应的数据就会报五零四，可能是网络慢，或者说上游服务器不能提供服务。那把这些 HTTP 状态码都掌握了，定位问题就变得非常的容易了。
