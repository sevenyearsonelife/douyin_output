Ping 命令五个神奇用法，看看你用过几个。第一个，一直 ping，默认情况下 ping 只发送四个包就会中断，还需要再次执行。这时啊你可以加一个杠 t 参数，持续 ping。这种方法通常用于持续的观察网络稳定性和性能。第二个，解析 IP 为主机名。如果你也想了解你 ping 的这个主机是哪一台机器，可以加一个杠 a 参数。这样在下面输出这里呢就会有个主机名，呃从而帮助您去判断它是哪一台机器，在内网中特别有用。第三个，你可以指定 ping 的次数，例如你写个脚本就可以 ping 一次来去加快它的速度。在 Windows 上是通过杠 n 参数，在 Linux 上是通过杠 c 来指定次数，例如一次。这样它 ping 一次就结束了。第四个，指定发送数据包的大小，你可以通过杠 l 来指定发送数据包的大小。

这种方式啊通常是测试服务器的网络吞吐量和这种丢包的情况，在数据包比较大、高负载的情况下进行去测试，效果会更好一点。呃可能有些同学呢也之前有了解过死亡之 ping，其实啊就是利用大规模的机器向一台目标主机发送大的数据包，造成网络流量瘫痪，从而把一个机器打挂，瞬间就可以挂掉。现在呢很多服务器都已经限制了接收 ping 数据包的大小，所以这种方法在目前基本上都已经不可行了。当然你你可以少量的设置数据包来满足你这种网络性能的测试。第五个，ping 网段，这个 ping 它默认是不支持的，你可以利用 cmd 里面的循环来实现 ping 网段。像这么一个循环就可以持续的将幺九二点幺六八的一点这个网段全部发送一个包去 ping。这些选项都可以组合着使用，以更好的进行网络故障排查。
