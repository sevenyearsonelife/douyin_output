灰度发布是一种主流的发布方案，大厂都在用。这里教给大家基于 Nginx 实现灰度发布，有两种方式。第一种基于权重的流量切分，Nginx 将用户流量按比例转发到新版本，也就是灰度版本。一旦新版本验证通过，将全部流量切换到新版本，或者逐步将部分流量切换到新版本。Nginx 实现基于权重的流量切分，实现也非常简单。在 upstream 中为不同的后端服务器配置权重即可。给大家实操演示一下，这里有三台主机，T 一为 Nginx 负载均衡器，T 二、T 三为 Web 一和 Web 二。打开 Nginx 配置文件。在这里定义了 upstream webserver，里边有两台服务器，T 二和 T 三，下面代理上面 upstream 组。按照这么一个配置，当你访问这个虚拟主机，它将会轮询转发到 T 二和 T 三后端服务器上。
