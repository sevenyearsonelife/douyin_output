那接下来呢，我们构建个镜像试试，呃，进到我有一个 web 项目目录下，然后这里有一个 Dockerfile，这个 Dockerfile 呢非常简单，就是引用一个 nginx 的基础镜像，将网站程序拷贝到 nginx 的网站根目录下。那我们就可以使用 buildctl 这个命令，使用 build 完成对这个 Dockerfile 镜像构建。第一个参数指定 Dockerfile 类型，啊，也就说明要基于 Dockerfile 配置文件来构建镜像。第二个参数将当前目录作为构建镜像的上下文，因为在 Dockerfile 中会执行一些拷贝文件啊，执行一些命令啊，它都是基于这个目录来去完成的。后面这个点表示 Dockerfile 文件就在当前目录下，默认读取的就是这样一个名称，如果不是个名称，你在这里呢需要明确的指定一下。

最后一个参数是输出构建镜像的参数，包括镜像以及镜像的名称和标签，后面加了一个 push 等于 true，就表示是将镜像构建完成之后再推送到该指定的镜像仓库里面，就是构建完镜像就会推送这个镜像到镜像仓库里，就不用再手动的操作了。当然你也可以 push 设置为 false，只让它构建出不推送，回车。好，这样呢就完成了镜像的一个构建，并推送到镜像仓库。如果你没有使用 Docker，也想构建镜像，那使用这个 buildkit 是一个最佳选择。
