通过一张图来给大家分享一下 Linux 系统性能分析都是有哪些常用的工具。请看图，这张图呢是 Linux 系统从应用层再到系统再到内核再到硬件所涉及的性能分析工具非常全面。如果你要想查看进程的系统调用，你可以使用 strace 命令。如果你要了解硬盘的 I/O 负载，你可以使用 iostat 命令，biotop。如果你要想查看系统打开的文件描述符，你可以使用 lsof 命令。如果你要想去管理网络，你可以使用 ip 命令。如果你要想去查看端口，可以使用 netstat、ss。如果你要想去查看内存，可以使用 vmstat 或者 free 命令。如果你要想查看 CPU，可以使用 top，pidstat 可以查看指定进程使用的内存、CPU。如果你要想去查看进程，那可以使用 ps。

如果你要想去实现网络抓包，可以使用 tcpdump。如果你要想去查看系统事件，可以使用 dmesg 命令。等等这些，都是在 Linux 系统性能分析中常用的工具。当然还有其他的，都可以啊尝试的去用一用，帮助你提高故障排查的能力。
