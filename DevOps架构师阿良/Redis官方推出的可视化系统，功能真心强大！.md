Redis官方推出的这一款可视化系统功能真的很强大，这里分享给大家。我们先看一下它的下面情况。Redis Insight是一款Redis的可视化系统，可以对Redis内存、连接数、命中率等等各方面的指标进行去监控，并且可以在同一页面上进入Redis的命令行终端。我们先使用Docker创建一个Redis实例，再使用Redis Insight进行对它监控。在创建Redis Docker实例的时候，将六三七九端口暴露出来，可以让外部访问这个Redis，也就是通过Redis Insight通过网络链接获取监控指标。好，Redis运行起来之后，那我们再使用Docker创建一个Redis Insight容器。

docker run -d redis insight -p 将它的八零零一端口暴露出来，它的访问端口是八零零一，然后指定redislabs呃redis insight。Redis Insight容器已运行成功，我们可以在浏览器中访问八零零一来访问它。好，这就到了Redis Insight的页面，这里让你允许协议，点击勾，然后点击继续。这里提示你是链接已经存在的Redis的数据库还是没有，我们已经有了Redis，那我们选择第一个，再选择第一个连接Redis的数据库。在这里输入，当我们启动的Redis容器访问它的地址和六三七九端口。写一个名字，比如说叫docker redis，密码和用户名都是为空，然后点击添加。

好，这就进入了Redis Insight里面，点击刚我们添加的Redis，它就开始进行对Redis进行去监控了。在Redis Insight首页可以观察连接的这台Redis，它的总共有多少K，连接数、命中率、运行时间等等指标。在下面browse这里可以浏览Redis实例的K及它的详细信息。啊目前我们这里面还没有任何K，所以看不到。在client这里可以进入Redis终端，并且在这里面呢你可以执行任意的命令啊，比如说我们创建一个K。然后我们再浏览，哎这里就能看到刚创建的这个K了，你所有的K都能在这里呢进行去展示出来。而这里呢也可以进去对stream数据结构的数据进行实时的展示。

下面分析这里可以对Redis内存进行去分析，比如在这里添加一个内存的分析，有两个选项，在线分析还是离线分析，第一个是离线分析，分析它是读取已有的rbd文件进行去分析，在线分析它是对Redis收集指标进行去分析，不过这个呢会增加Redis的资源的开销。比如说我们在线分析，点击分析。这里有三个图表，第一个显示不同类型的K占用内存的情况，第二个不同类型的K它的数量，第三个内存使用趋势和释放的一个情况。在这里也可以看到所有 key 占用内存的一个情况及它的数据类型。Profile 它用于去统计当前时间执行命令的一个情况，这里你需要点击启动这个 profile 收集，进入到 redis 这个客户端里面，比如执行一个 k，那么停止，这里就会收集到我们刚执行的那个 k 命令，任意的命令呢在这里都会给你统计出来。

所以你想知道哪个时间段执行了哪些指令，就可以在这里进行收集了。这是慢查询日志，超出一定的阈值都会被记录下来，方便您进行去分析哪些命令执行慢，好去优化。下面是关于 redis 的配置，在这里呢你很多的参数可以直接的进行去修改，就不用去修改配置文件了，也是非常方便。包括了解当前 redis 运行的参数都是有哪些值，这里是呈现出 redis 的客户端列表，是动态实时展示的，只要连接到 redis 这里都会呈现出来，可以帮助了解有多少个并发客户端。这些就是 redis inside 的主要的一个功能，通过 redis inside 可以直观的了解 redis 运行状态，对故障排查、性能分析也提供很多的帮助。如果你在用 redis，建议大家都安装一下 redis inside。感谢您的观看，下次见。
