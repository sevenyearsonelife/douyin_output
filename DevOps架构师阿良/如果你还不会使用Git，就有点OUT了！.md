如果你还不会使用 Git 就有点 out 了，来一张图给你讲明白。假设在 Git 上有一个项目代码仓库，你现在呢需要对这个项目代码再进行开发。首先你需要使用 git clone 命令将该仓库呢下载到本地，然后进行新增代码、修改 bug 等操作。当你完成修改之后，使用 git add 命令将代码变更添加到本地的暂存区，再接着使用 git commit 命令将它提交到本地的 Git 仓库，最后再使用 git push 命令将本地仓库中的更改推送到远程的 Git 仓库。那如果你同事提交了新代码，你想获取新的代码，你就需要使用 git fetch 这个命令，再从远程仓库中获取最新的更改。但是啊它不会合并到当前的分支。

啊在获取这个更改之后，更新的代码再使用 git merge 这个命令，再将这些更改合并到本地的分支，就可以继续的再开发了。如果你提交了新代码，呃其他的同事如果说获取你的新代码也是同样的流程。最后再给大家分享一个 Git 常用的命令速查表，帮助你啊对这个 Git 命令进一步的进行去熟悉，值得保存和学习。
