面试官问，说一下 HTTP 是怎么工作的，你这么回答给满分。分为六步，第一步，建立 TCP 连接，无论任何请求都是要先建立 TCP 连接，再进去通信。一旦建立了 TCP 连接，浏览器就可以与服务器进行 HTTP 通信了。第二步，客户端发送请求。客户端它将你输入的地址，再加上其他信息，构建一个 HTTP 请求。那这个 HTTP 请求呢，包括了有请求方法，你请求的 URL，还有 HTTP 版本号，还有你浏览器、客户端相关的信息，等等这些都会包括在 HTTP 请求中，发送给服务器。第三步，服务器处理请求。服务器它收到浏览器的这个请求后，会根据请求的方法、URL 执行相应的操作。如果你请求的是一个静态内容，服务器就直接返回文件了，例如 HTML、CSS、图片等等。

如果你请求的是一个动态内容，有具体的编程语言来给你执行这个文件，并生成相应的内容，例如 PHP、Java 等。第四步，服务器它发送响应。当服务器处理完这个请求后，会发送一个 HTTP 响应给浏览器。响应内容它就包括有 HTTP 版本、状态码、服务器环境信息等等。第五步，客户端处理响应。浏览器它接触到服务器的响应后，它会根据这个响应内容的类型进行相应的处理。比如 HTML 浏览器啊，它会解析成具体的 HTML 内容，展示网页。那如果它是一个文件，它就会提示你下载。第六步，断开 TCP 连接。那一旦服务器返回的数据，就要关闭这个链接了。那除非你配置了 keep alive 保持链接，否则就是直接就进去关闭了，执行 TCP 四次挥手。你就把这六步给面试官说一下，就是没问题的。
