一张图让您明白计算机网络通信流程。请看图，假设 PC 一和 PC 二这两台主机通信，PC 一主机会先在应用层将数据封装到协议中，例如 HTTP 请求。继续经过表示层，将数据转化为合适的网络传输格式。继续经过会话层，建立会话状态。继续经过传输层，添加 TCP 或者 UDP 报头，主要是源端口和目标端口，这个称之为段。继续经过网络层，添加 IP 报头，主要是源 IP 和目标 IP，这个称为包。继续经过数据链路层，添加以太网帧，也就是源 MAC 和目标 MAC，这个称之为帧。最后经过物理层，将数据帧转化为比特流，并通过网线进行传输。以上称之为封装。PC 二主机从网线接收到比特流，并将其转化为数据帧。继续经过数据链路层，从数据帧中将数据提取出来。继续经过网络层，将数据包中的数据提取出来。

继续经过传输层，将数据段中的数据提取出来。继续经过会话层，恢复双方之间的会话状态。继续经过表示层，根据数据格式将数据转化为原始的格式。最后经过应用层，根据协议的规范将数据提取出来，供应用程序进行去使用。这个过程称之为解封装。简而言之，封装主要是从第七层到第一层，一步一步添加报头。而解封装是从第一层到第七层，一步一步去除添加的报头。
