编写一个 Shell 脚本，在多台 Linux 的服务器上执行命令，这个需求实现非常简单。既然是多台 Linux 的服务器，你肯定得有一个文件保存这些目标服务器啊。啊，所以我们先创建一个 host_list. txt 文件来保存目标操作的服务器。为了更好的进去描述这个文件啊，在开始啊我们做了一个注释来去声明下面呢应该怎么格式进去写。这里有两个目标主机，一点七二一和一点七三，分别指定呢操作的用户名和密码及它端口。后续啊你还可以继续去增加更多的这个主机，保存。然后打开我们实现的这个脚本，这个脚本呢也非常简单。首先判断脚本参数有没有传入值，呃如果没有的话给予一个提示。将主机列表保存到一个变量文件中，方便下面进行去操作。到了 and 是获取脚本传入所有参数并保存这个变量，方便下面进行去使用。

for 循环来去读取这个文件中的所有的内容，对里面的主机呢进行挨个的进去遍历。for 循环的值是来自于这个命令返回值，这个命令是通过 awk 取出主机文件列表里面的所有非注释的行，只获取下面实际的主机，它会获取主机列表中的第一列主机 IP，然后再通过这个 IP 分别取出用户名、密码和端口。比如第一次它会遍历到一点七二这个 IP，然后我们再通过 awk 再根据这个 IP 匹配出它的第二列，也就是用户名。密码和端口都是同样的道理，取出第三列和第四列分分别赋予变量，然后再打印这个 IP。

啊，最后呢使用 sshpass 这是一个关键啊，因为实现这个脚本的关键就是在于如何免交互登录到目标服务器上执行命令，而 sshpass 就可以做这件事情，它会 ssh 连接到目标主机上并执行 Shell 命令，分别将密码、端口、用户和 IP 传递给 sshpass 和接收脚本的命令行参数传递给它。通过这么几行脚本呢就实现了可以在多台 Linux 的服务器上批量执行 Shell 命令。来我们看一下这个效果，执行这个脚本后跟比如 ls -l，它会连接一点七二七三分别在默认工作目录下呢去执行 ls -l 去查看文件，也可以去查看它硬盘信息，df -h，这是一点七三的输出，这是一点七二的输出。啊，任何的命令呢都可以去执行，比如 ip a d 点二，可以很方便的管理多台 Linux 的服务器。

采用相同的思路举一反三，还可以去写系统巡检、嗯磁盘监控等等这些需求。如果你是一名 Linux 的运维者，那一定要把这个思路和脚本实现具体熟悉一下，对你以后呢也会有很多的帮助。
