Linux 这款转发工具太强大了，可以转发任何服务，我之前用它做过很多次跳转，真方便，这里分享给大家。直接教给大家看怎么安装，在它的 GitHub 项目这里下载这个源码包，在发布这里。我这里呢已经下载下来了，然后让它上传到我们这一台机器上，啊假设我就用这一台服务器做跳转，将这里进去解压，先让它安装到你的系统中，直接编译安装。然后 make，make install，直接安装。好，这就安装到系统上了，然后我们直接可以执行 rinetd 来启动这个服务。在启动之前我们先配置一下你的转发规则，在 etc 下创建一个它的配置文件，配置文件名字和它的名字是一样的，别写错了。

在这里呢总共要写四列，第一列是要写本地的 IP 地址，我这里的 IP 地址呢是一点七二，它本身是一个跳转嘛，是要访问这台机器的哪个端口，将请求转发到目标端口。这里呢就是访问我该机器的哪个端口，假设我四个二，现在我希望访问我该机器的四个二，将请求啊转发到目标主机一点七三的二二二端口。啊那我这里呢就配置好了一个转发规则，那任何的服务端口都是可以转发的，保存，保存完成之后直接启动它。启动后有一个对应的相关进程，说明就启动成功了。接下来呢我们测试一下配置的这条转发规则是否成功了。呃我们 ssh 本机的 IP 一点七二，它的二四个二端口，然后输入一点七二，它的 ssh 密码，这里呢还要输入一个杠 p 指定端口。

好，这里呢就连接到了一点七二这台服务器上，通过 ssh，可以看一下这主机名啊，与我 rinetd 这个主机名是不一样的，说明它们不是在一台上，哎这样就成功了将请求转发过去了。啊然后我们再退过来，再看一下它配置文件，那这个配置文件呢你都可以定义多条，转发任何的服务，比如像 rdp 服务，呃像 mysql，像任何的服务你都可以配置这里，非常的简单。如果你有跳转或者转发需求，就可以使用这个工具了，非常的方便，推荐大家使用。
