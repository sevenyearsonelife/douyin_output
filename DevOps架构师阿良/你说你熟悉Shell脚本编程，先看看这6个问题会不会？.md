你说你熟悉 Shell 脚本编程，先看看这六个问题会不会？第一个问题，为啥你执行的 echo 和别人执行的 echo 不一样呢？举个例子，echo 打印个一二三，我希望在一二三加一个换行符，执行，可以看到没有达到我们的预期。这是因为默认情况下，echo 它保留了斜杠里边原有的意思，直接跟原样输出。如果你要想让这个换行符起到它的作用，需要加杠 e 参数，启用斜杠转义。第二个问题，双引号和单引号有什么区别？举个例子，我定一个变量 a b c 等于一二三，我希望把它打印出来，a b c 这个变量，执行，可以看到并没有打印出来 a b c 这个变量，这是什么原因呢？这是因为单引号啊保留里面所有的 dollar，你如果要引用变量，你需要使用双引号，这样就可以打印出 a b c 这个变量了。

问题三，定一个 a b c 变量，export 定义这个变量，前后差在哪里？这是一个局部变量，只对当前的 Shell 进程有效，对其子进程就失效。export 是对于当前的进程及子进程都会生效。假设你定义着一个 Shell 脚本，里边有个变量，希望在它的子脚本中来去引用，那就可以使用 export 进行去定义才行。问题四，dollar and 和 dollar 星有什么区别？dollar and 是将脚本的每个参数作为一个独立的参数看待，dollar 星号是将脚本的每个参数合并为一个独立的字符串看待。第五个问题，and and 和两个竖杠有什么区别？and and 是逻辑与，表示上一个命令执行成功，也就是退出状态码为零才会执行后面这个命令。

两个竖杠表示逻辑或，当前面的命令执行失败，也就是退出状态码非零才会执行后面的命令。举个例子，ls 执行成功才会执行后面的打印，如果执行失败就执行后面的 no，可以看到 yes 执行了，说明执行成功。如果我将这个命令呢写错，看执行失败就会执行后面的竖杠竖杠后面的命令。第六个问题，dollar 两个小括号和一个小括号和一个花括号这三个有什么区别？dollar 两个小括号呢它表示里边执行一个算术运算，比如一加一，echo 一下，就可以做基本的算术运算啊。一个小括号是用于执行 Shell 命令，比如 a，那么 echo 一二三这个命令结果就会保存到 a 这个变量中。dollar 花括号是用于引用一个变量，echo 一下就可以引用这个变量啊。以上这六个问题你都会吗？如果都会的话，说明你熟悉 Shell。
