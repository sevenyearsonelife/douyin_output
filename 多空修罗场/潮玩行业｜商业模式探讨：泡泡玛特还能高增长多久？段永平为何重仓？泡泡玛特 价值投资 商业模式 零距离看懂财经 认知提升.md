我操，段永平买成泡泡玛特第二大股东了。我第一反应是老段是不是也开始抽盲盒了？一个卖玩具的公司居然能让段永平砸进去上百亿港币，而且他前几年不是还说看不懂泡泡玛特吗？你这个反应其实和绝大多数投资者一模一样。因为很多人看到泡泡玛特看到的是塑料玩偶，但段永平看到的是 IP，很多人看到的是盲盒，但段永平看到的是迪士尼，很多人看到的是年轻人的冲动消费，但段永平看到的是品牌资产。所以这次真正值得研究的不是泡泡玛特涨了多少，而是为什么一个长期研究茅台、苹果、腾讯的人会突然重仓一家潮玩公司。关键是段永平这次说的话也太夸张了，他说王宁未来可能和乔布斯一个级别，甚至商业理解比乔布斯还强一点，这评价是不是太高了？如果放在三年前，很多人会觉得这是吹牛，但放在今天，你会发现他可能真不是随便说说。

根据港交所披露的信息，段永平相关账户持股比例已经超过百分之五，成为泡泡玛特重要股东之一。更有意思的是他曾经把中国神华换成泡泡玛特。你想想，一个价值投资教父把煤炭龙头卖了，换成卖 Labubu 的公司，这背后一定发生了什么。那到底发生了什么？答案可能就两个字，看懂。段永平以前其实并不看好泡泡玛特，公开说过看不懂，甚至拿电子宠物呼啦圈举例，担心这只是阶段性的流行。但后来重新研究完财报以后，他的态度发生了一百八十度转变，因为他发现自己原来研究错了对象，泡泡玛特根本不是玩具公司，而是一家 IP 公司。什么意思？举个例子，你觉得迪士尼最赚钱的是什么？电影？乐园？其实都不是，是 IP。米老鼠几十年前创造出来，到今天还在赚钱。漫威拍电影赚钱，卖手办赚钱，卖衣服赚钱，开主题乐园赚钱，授权还能赚钱。

IP 最大的魅力就在于一次创造反复变现，而泡泡玛特的逻辑越来越像这样。很多人一直以为泡泡玛特卖的是盲盒，但盲盒只是销售形式，真正卖的是 Labubu、Molly、Crybaby、School Panda 这些 IP。但说实话，我还是有点不理解，一个玩偶凭什么卖几百块？因为它满足的是人类最古老的需求，收藏、炫耀、归属感和情绪价值，这其实和茅台没有本质区别。一瓶茅台成本一百块，卖两三千块，为什么？因为它承载身份认同。Labubu 也是一样，成本几十块卖几百块，二手市场甚至炒到几千块，本质上卖的都是心理价值。巴菲特当年研究可口可乐，研究的是品牌，今天研究泡泡玛特，本质上研究的也是品牌。所以潮玩其实是一种消费升级。准确说是情绪消费升级。

过去二十年中国消费升级围绕的是房子、车子、家电，未来二十年越来越多会围绕精神消费和情绪消费。宠物经济、游戏、二次元、演唱会、潮玩其实都属于这一类。以前消费者买的是功能，现在消费者买的是快乐。那泡泡玛特到底有多赚钱？如果只看数据会非常震撼，二零二四年公司营收超过一百三十亿元，同比增长超过百分之一百，调整后净利润超过三十四亿元，同比增长接近百分之一百八十六，毛利率接近百分之六十七。这个毛利率是什么概念？很多制造业企业只有百分之十左右，汽车行业普遍十几个点，泡泡玛特已经接近奢侈品生意了。而且更关键的是利润增速远远快于收入增速，这说明规模效应正在释放。但最近股价不是跌。跌得挺厉害嘛，网上天天有人喊泡泡玛特见顶。这恰恰是最值得讨论的地方。很多人以为股价下跌是因为公司不行，实际上更多是因为预期太高。

过去一年，市场把泡泡玛特当成成长神话，Labubu全球爆火，海外收入暴增，股价一路狂飙。结果财报出来以后，业绩虽然很好，但未来增长指引没有市场想象的那么疯狂，于是很多资金开始兑现利润。简单说，不是公司差，而是市场之前太乐观。这和很多牛股好像都一样。完全一样，腾讯跌过百分之七十，茅台跌过百分之六十，英伟达也跌过百分之五十。伟大的公司和伟大的股票从来不是一回事。价值投资最重要的一件事就是区分公司和股价，公司可能越来越好，但股价短期未必一直涨。反过来，股价涨得太快，也可能透支未来几年成长。那泡泡玛特最大的看点是什么？海外，绝对是海外。过去几年最惊人的变化就是泡泡玛特开始从中国公司变成全球公司，海外收入增速远远高于国内市场，东南亚、欧美、中东市场都在快速扩张。

如果未来 Labubu 能够像 Hello Kitty 一样成为全球流行文化符号，那公司的天花板将被彻底打开。很多投资机构现在看泡泡玛特已经不是按照中国潮玩龙头估值，而是按照全球 IP 平台估值。那最大的风险呢？其实只有一个，IP 能不能持续诞生。因为整个行业本质上不是制造业，不是零售业，甚至不完全是消费品行业，而是创意产业。如果未来十年只有 Labubu 一个爆款，那估值就有问题。但如果未来十年不断出现新的 Labubu，那情况就完全不一样了。这也是市场最大的分歧。没错，空头认为 Labubu 只是运气，热度总会过去，今天像 Hello Kitty，明天可能像电子宠物一样消失。

多头认为 Molly 火过，Dimoo 火过，Skullpanda 火过，现在 Labubu 又火了，说明公司已经掌握了制造爆款的方法论，不是一个 IP 成功，而是一个平台成功。那除了泡泡玛特，还有谁值得关注？名创优品、Top TOY、五十二 TOYS、奇梦岛这些都值得关注，但它们和泡泡玛特有本质区别。名创优品最大的优势是渠道，全球数千家门店。Top TOY 本质也是渠道扩张逻辑，而泡泡玛特最核心的资产是 IP。渠道公司靠开店赚钱，IP 公司靠时间赚钱。一个爆款 IP 可能赚钱几十年，所以资本市场愿意给予更高估值。听到这里我突然发现这家公司越来越不像零售公司。你终于抓住重点了。很多人研究泡泡玛特的方法从一开始就错了，他们把它当玩具公司、零售公司、消费公司，所以永远看不懂。

如果你把它当中国迪士尼的早期版本，很多东西突然就顺了。那最后一句话总结泡泡玛特。白酒卖身份，饮料卖习惯，调味品卖刚需，新能源汽车卖未来，而泡泡玛特卖的是年轻人的情绪和梦想。真正让段永平兴奋的不是 Labubu 今天卖了多少，而是王宁有没有机会创造出下一个米老鼠。因为一个爆款玩偶值几个亿，一个世界级 IP 可能值几千亿，而这恰恰是泡泡玛特多空双方争论最激烈的地方。空头看到的是盲盒，多头看到的是迪士尼。未来十年，市场会给出答案。以上仅为个人学习思考，不构成任何投资建议。投资有风险，决策需谨慎。如果觉得有收获，欢迎点赞关注，我们下期见。
