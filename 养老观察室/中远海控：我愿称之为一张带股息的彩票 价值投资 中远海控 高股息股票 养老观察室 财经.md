你买中远海控到底是为了分红，还是在赌下一轮航运周期？都有。说的专业一点，它是我组合里的弹性仓。说的诚实一点，它就是我给自己买的一张航运彩票。投资博主公开承认自己是赌狗？承认啊，但我不是把房本拍在桌上，大喊一句梭哈是一种智慧。我只是愿意拿一小部分仓位去赌一个赔率足够高的未来。你赌什么？全球贸易突然爆发？全世界又开始缺船？以前我赌的，可能真是下一轮运价周期什么时候来。但现在不一样，中远海控这张彩票其实已经刮开一角了。截至七月三十一日，C C F I 综合指数已经达到一千八百五十七点，比去年同期高了大约五成，反映即期市场的 S C F I 超过三千两百点，差不多是去年同期的两倍。所以现在真正的问题不是运价什么时候上涨，而是已经涨起来的运价到底能维持多久，又能有多少真正变成中远海控的利润、分红和回购。

等等，C C F I 同比涨了五成，S C F I 都翻倍了，你这还叫什么等待开奖？不是已经中奖了？只能说刮出了几个数字，还没连成一条线。最近一周，C C F I 从一千九百零一点回落到一千八百五十七点，下降百分之二点三，但 S C F I 却从三千零六十三点升到三千两百零六点，单周又涨了接近百分之五。一个跌，一个涨，这两兄弟是不是没对过口径？口径本来就不一样，S C F I 更像现货市场，反应快，货主今天着急，船公司明天就敢涨价。C C F I 还包含大量长约运价，动作更慢，更接近船公司真正收到的综合价格。所以现在的状态可以理解成，现货市场已经开始兴奋，长约市场还在观察。翻译一下。市场已经在喊要涨价了，财务报表还在说你先别急，我月底再确认。

所以这轮高运价能不能真正兑现，要看它能不能维持几个月，而不是只看一周的指数蹦了多高。可中远海控一季度利润不是跌得很厉害吗？对，二零二六年一季度，它完成了将近六百九十二万标准箱的货运量，同比增长百分之六点七，船运的更多，箱子也没偷懒。但因为当时 C C F I 均值同比下降百分之十六点三二，公司收入下降百分之十点六三，规母净利润直接下降百分之四十九点七五，只剩下五十八点七七亿元。货拉的更多，利润却少了一半。这就是航运股，它最核心的问题从来不是我今年运了多少箱，而是每个箱子我到底能收多少钱。你可以让船员更努力，让码头效率更高，让货运量继续增长，但单箱收入一掉，利润还是会很诚实的往下跳。所以它还是周期股？

当然是，但一季度财报讲的是一季度的低运价，现在现货运价已经明显上去了，所以我们不能拿四月份看到的后视镜，判断八月份前面的路。这期真正值得看的是二季度往后，运价反弹能不能覆盖一季度留下的利润缺口。最近美伊打打谈谈，霍尔木兹海峡天天上新闻，是不是只要那边继续乱，中远海控就继续赚钱？先别把中远海控和中远海能塞进同一个集装箱。霍尔木兹首先影响的是石油、天然气和油轮，不是每一枚导弹飞过去都能直接落进中远海控的利润表。那和集装箱航运有什么关系？关系主要有三层，第一，油价、燃油成本和战争保险费可能上升；第二，部分航线需要提高战争附加费、运河附加费和拥堵费；第三，也是最重要的，如果冲突继续向红海和曼德海峡扩散，船舶就要绕行，航程变长，同样数量的船能够运输的货物就会下降。

上海航运交易所也明确说明，S C F I 统计的运价中包含燃油、战争、港口拥堵和运河等附加费，所以运价上涨不等于这些钱全是纯利润，有些是船公司多收的钱，有些只是拿来补燃油、保险和绕路成本。那最近到底是越来越危险，还是快谈成了？两件事同时发生，一边在谈霍尔木兹海峡恢复通行，另一边伊朗提出的收费、管理权和保险安排，又让航运公司觉得难以执行。红海方向也。重新出现船舶改道和安全威胁，这就是航运市场最折磨人的地方。新闻每天都在说快谈成了，船东却要问，保险降了吗？船真的敢走了吗？出事以后有人赔吗？只要这三个问题没有答案，航线就很难完全恢复正常。所以别人谈判，你看运价。没办法，航运股有时候就是这么不讲情面。世界越顺，船走得越快，有效运力越多，运价反而可能越便宜。世界越拧巴，船绕得越远，仓位反而越值钱。

对人类来说，当然是和平更好，对航运股来说，和平来得太快，有时还真不一定是利好。你这话说的好像战争持续，中远海控就高枕无忧了。完全不是。现在支撑运价的不只是需求，还有大量运力被绕航吃掉了。一旦红海和苏伊士航线真正恢复，航程缩短，市场可能一次性释放相当于全球百分之六到百分之七的集装箱运力。与此同时，行业新船还在不断交付，运力扩张可能继续快于货量增长。也就是说现在看起来缺船，可能只是船都在绕远路。对，船不是消失了，只是出去旅游了一大圈。一旦最短路线重新开放，它们集体提前回家，市场会突然发现原来船还挺多。所以这张彩票最大的风险恰恰不是冲突继续拉扯，而是某一天谈判真成了，红海真恢复了，保险真降了，新船还正好全部下水，到时候运价掉下来的速度可能比赌狗删除自选股还快。既然运价说跌就跌，周期也没消失，你为什么还拿着？

因为今天的中远海控和过去那家一到周期底部就要担心怎么活下去的航运公司已经不是一回事。截至二零二六年一季度末，公司现金及现金等价物接近一千四百九十七亿元，资产负债率只有百分之四十点九。这些现金不能直接让股东排队去财务室领，公司还要造船、买箱子、投码头、更新绿色船舶，但它至少意味着周期低谷来了，中远海控有钱熬，周期机会来了，它也有钱扩张和回报股东。回报股东主要还是分红。二零二五年中远海控归母净利润约三百零九亿元，中期每股分红零点五六元，末期零点四四元，全年合计每股一元，现金分红总额约一百五十四亿元，差不多拿出了归母利润的一半。今年七月公司又推出新一轮回购计划，A 股计划回购五千万到一亿股，预计金额七点七亿到十五点四亿元，回购以后全部注销。截至七月底已经花了约四点二二亿元。所以你说它是带股息的彩票。

对，普通彩票没中就是一张废纸，中远海控没等到超级周期，至少还有船、码头、现金，以及一家愿意分红、愿意注销回购股份的公司。但注意，分红不是保底合同，它拿出的是利润的一部分，如果利润掉了，哪怕分红比例不变，每股分红也可能下降。我喜欢的是它愿意分钱，不是幻想它的钱永远分不完。中远海控现在还有港口和供应链业务，再过几年会不会就不算周期股了？码头确实更稳定，但现在还改变不了主次。二零二五年，中远海控集装箱航运业务收入约两千一百零七亿元，码头业务收入约一百二十亿元，仅看收入规模，航运业务是码头业务的十七倍以上。那码头不就是个配菜？不能这么说，码头是压舱石，能增强航线网络，也能提供更稳定的现金流，但压舱石的作用是让船不容易翻，不是把船变成一座水电站。只要绝大部分收入和利润还要看集装箱运价，中远海控就仍然是一家周期公司。

更准确的说法是，它没有摆脱周期，它只是变成了一家更有钱、更稳定，也更有能力利用周期的公司。所以你平时拿着它最大的乐趣是什么？每天刷运价指数？有时候我会想象一个画面，大海上一艘又一艘中远海控的货轮，从上海、宁波、新加坡开往欧洲、美洲和中东，船上堆着成千上万个集装箱，里面装着汽车、家电、衣服，也可能装着义乌发明出来我完全叫不出名字的小商品。我当然不可能拥有整艘船，但作为一个小股东，每艘船上或许总有那么几个集装箱，创造出来的利润有我一份。你那几百股能分到几个集装箱？我怕最后只能分到一个箱门。一个箱门也行，至少全球贸易每流动一次，我在里面还能占个铰链的位置。这就是持有股票最有意思的地方，你花的不只是一笔钱，你实际上是在给自己买下一小块商业世界。最后总结，中远海控到底是一只高股息股，还是一只周期股？

它首先是一只周期股，高股息是周期利润愿意分给股东之后的结果。大量现金提高了它熬过低谷的能力，码头和供应链增强了稳定性，分红与注销式回购则让普通股东真正拿到了一部分经营成果。但它最诱人的地方仍然是周期向上时巨大的利润弹性。所以对我来说，中远海控不是养老底仓，它是我组合里一张带股息的彩票，而且这张彩票现在已经刮开了一角，运价已经起来了，美伊和红海局势还在反复，接下来要看的是这些高运价能不能维持足够久，最终进入利润表，再从利润表进入我的分红账户。我不会满仓赌它，也不会指望它按时兑奖，但我愿意拿一小部分仓位给下一次全球航运的大波动留一张船票。所以投资博主最后还是承认了，你就是赌狗。纠正一下，是看资产负债表，控制仓位，不抵押房本的理性赌狗。你会把中远海控当成高股息股、周期股，还是一张带股息的彩票？

你现在拿着它，是在等分红，还是在等这张彩票彻底兑奖？
