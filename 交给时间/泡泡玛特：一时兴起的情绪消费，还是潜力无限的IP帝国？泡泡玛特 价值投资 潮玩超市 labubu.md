于是一六年以后呢，他们就改变了，签约艺术家，拿 IP 授权，买断 IP，从潮玩的超市渠道转型为 IP 的运营平台。那转型以后呢，他们就不再是帮别人倒卖玩具的一家公司了，它更像是潮流赛道的唱片公司。拉布布呢就相当于顶流歌手，泡泡玛特负责签约艺术家，做 IP 孵化、产品落地、供应链生产，再通过线下门店和线上的渠道卖给全球的消费者。那这样的模式有什么魅力呢？首先你真正掌握了定价权，毛利率可以大幅的提升，并且 IP 在你的手里不会被别人卡脖子。而且一个 IP 可以反复变现，还能沉淀出属于自己的品牌心智，以及搭建艺术家平台，用矩阵分散单一 IP 的风险。那么以上这些优点呢，他们都做到了。现在的泡泡玛特就是一家高毛利啊强品牌心智，有大量头部艺术家，有 IP 矩阵的公司。这会引发一个滚雪球的复利效应。
