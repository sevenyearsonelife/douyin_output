当然腾讯它也不止一次是这样了，它之前还有过一次养龙虾的新闻，也是一样的剧本，就当天有一个新闻，然后当天涨百分之十，后续又全部跌回去了，这些都是很典型的例子。我们再来一个例子，小米之前它要开新车发布会嘛，发布会的前一天还是前两天，单日股价暴涨百分之十，那很多人就问小米大涨了要不要追，是不是基本面要变好了？我当时又出视频，我说这个大概率还是要掉头向下的。那为什么在我的眼里发布会啊，包括这些热点新闻，全部都不能算是真正的利好呢？一家公司基本面真正的利好怎么看啊？我们再回到小米这个例子来讲，它开发布会不算是利好，你真正的利好要看它造这个车的销量，而且你要知道它卖一台车它能赚多少钱嘛。

如果是一台新车，我们普通人你从过往的财报里面查不到这个新车的毛利率是多少，最后的净利率是多少，甚至是因为发布会还没有开，定价都还没有出来，那你要怎么判断它未来会不会赚更多的钱呢？给小米这家公司是吧？有可能它这款车上市以后一个月两个月都卖的不好呀，对不对？所以你发布会不能当成利好，反而是后面的财报数据发布，你才可以看得到这辆车它到底赚了多少钱。包括小米发的一些新手机，苹果发布一些新手机也是一样的，发布会当天都算不上是什么利好，除非它把那个销量给公布出来了，比如说大定多少多少台超预期了，这样才算是利好。那大部分情况下呢，之所以发布会就是会有上涨嘛，也是因为它的热度会在那一天大幅的上升，就很多人会在那个时候想着去买，因为很多人就在那个时候才知道的这件事，那资金其实往往就是在这个时候出货的啊，聪明钱。

所以真正看是不是利好要看后面手机的销量怎么样，电车的销量怎么样，对不对？那腾讯最近的几次异动也是一模一样的，它的基本面没有因为一个新闻就彻底变好了，只不过是短期的热度上来了，哎，短期有一个让大家很兴奋，很有想象力的空间出来了，那这些就很容易识别，这不可能为它的股价提供长期有效的估值支撑。你到底是不是利好要看你未来的财报，它能不能给你持续的盈利嘛。然后有一句话我觉得是非常有道理的，就是没有一家公司的基本面是突然变好的，它都需要有一个过程，就算是量变引起质变也需要大量的积累。那腾讯我个人现在认为就是还在积累的阶段，无论是它微信的小薇也好，陆续要推出一的一些新游戏也罢，还是说它的 work buddy 也好， code buddy 啊，都是在积累的过程。
