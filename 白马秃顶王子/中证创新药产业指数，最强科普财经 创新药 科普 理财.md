截至二零二六年的三月，中证创新药产业指数的总市值突破了二点四万亿，成分股的平均市值在四百八十亿左右，所以流动性比较友好，进出也相对顺畅。其实每次聊到创新药，大家最容易犯困的就是两个词，第一呢是 C X O，第二个是 A D C，这听起来挺复杂，其实逻辑特别简单。先说 C X O，全称是 Contract X Organization，意思是某个合同组织，中间的这个 X 代表的是一个变量，如果 X 变成 research，那 C X O 就变成了 C R O，意思是合同研发组织。如果 S 变成 sales，那 C X O 就变成了 C S O，意思就是合同销售组织。总之呢，你可以把 C X O 理解成创新药行业的幕后服务商。

一家药企想要研发新药，周期长，投入大，流程极其复杂，从早期研究、临床实验到生产申报，每一步都需要专业团队。大部分药企不会把所有的环节都自己干，太累了，而是外包给更专业的公司。那这类专门做研发、临床、生产外包的企业就叫 C X O，所以只要行业在创新，药企在烧钱研发，它就持续有订单。所以在中证创新药产业指数里边，C X O 占比是相对比较高的，目前在百分之二十左右，属于指数很重要的组成部分。那再来说这个 A D C，这个是近几年非常具有爆发力的方向，你可以把它理解成带精准导航的生物导弹。大家都知道啊，传统的化疗那是不分好坏细胞，全都通杀，副作用比较大，患者也比较痛苦。

但 A D C 药物相当于给药物装上了定位系统，专门识别癌细胞精准攻击，对正常细胞伤害更小，疗效更强，安全性也更高，那患者也没有那么痛苦，是目前全球创新药商业化空间非常大的方向之一。咱们国内企业在这个领域就已经走到了世界的前列，指数里布局 A D C 的公司也非常多，权重大概占比在二十二到二十五左右，像荣昌生物的一款 A D C 药物的海外授权金额就达到了四十二点三亿美元，这就是实打实的技术价值。OK，顺着主线接着往下走啊，为什么那么多机构和个人都看好这个指数呢？哎，其实它靠的就是非常严谨的选股规则，它第一步就做流动性筛查，按过去一年日均成交额排序，直接剔除后百分之二十的股票，确保成分股具备充足的流动性，那普通投资者和大资金都能进出顺畅，不会出现想买买不进，想卖卖不掉的情况。

第二步就是产业纯度卡死，只纳入创新药研发、临床、产业化核心企业，如果是仿制药、原料药、医药流通类的就全都排除，成分股数量严格控制在不超过五十只，保证赛道的纯粹度。那第三就是集中度严格管控，单只股票的权重上限设为百分之十，前十大成分股合计不到百分之五十，就算单一龙头出现波动也不会带崩整个指数，分散风险的效果也非常明显。再就是调仓的规则也很克制，单次调整比例不超过百分之二十，搭配缓冲区机制也不会大比例的调进调出，指数走势呢？也更稳，也能降低跟踪误差。好，接着往下看基本面啊，就更硬核了。二零二五年的国内获批创新药就达到了七十六个，较二零二四年的四十八个肯定是大幅增长啊，也创了历史的新高。

全年的创新药海外授权交易一共是一百五十七笔，总金额高达了一千三百五十六点五五亿美元，是二零二四年的二点六倍，全球的话语权也大幅的提高。那今年二零二六年前两个月也延续了爆发的态势，海外授权交易四十余笔，总金额超过了六百二十亿美元，几乎达到了二零二五年全年的近一半。那ADC双抗等前沿方向也占比超七成。另外，指数成分股平均研发投入占比超百分之十五，那部分龙头企业的研发费也将近百分之二十，这就远远的高于医药行业的平均研发水平。那这种持续的高投入也增加了创新药企业的管线厚度，仅二零二五年就有超三十个创新药品进入临床三期，十二个品种提交上市申请。哎，刚刚各位客官是不是听到了一个非常专业的词汇叫管线厚度呢？咱不着急，我稍微解释一下，你们很快就能明白。

管线厚度就是创新药企业手里正在研究的、做临床实验的、快要上市的和已经上市卖钱的所有新药加起来的储备清单。有的公司就靠一款药撑着，这叫管线薄，一旦卖不动或者临床失败，公司就没有更好支撑收入的办法。那有的公司呢，从早期研究到临床一期、二期、三期，再到上市商业化，一层一层梯队特别完整，这个药不行，下一个马上接上来，所有企业利润也能很好的持续，这就叫管线厚。所以管线越厚，公司越安全，成长越稳，创新药的价值也就越实在。哎，是不是一解释就懂？这就是科普的价值，赶紧点上关注加收藏。OK，接着往下说啊，其实很多投资人呢都怕创新药被政策影响，不过这也是事实，但是你想一点就会发现，创新药指数天生就比普通医药指数能更好的应对政策波动。

你看啊，仿制药、原料药这些基本上就是拼成本、拼价格，你来个集采，来个降价，利润一下子就被压没了，业绩很容易就跟着崩。但创新药不一样，它靠的不是低价走量，而是独家技术、靶点和临床价值。一个药如果真的临床效果好，能解决别人解决不了的问题，哪怕有政策调整，它依然有不可替代的地位，依然有定价空间和市场需求。再加上真正的创新药公司都在做全球化布局，国内市场只是一部分，像海外授权、海外上市、出海外权益都是重要的盈利部分。这边有政策波动，那边海外收入也能顶上，相当于左右两个口袋，所以风险也会被自然的分散掉。而且创新药的逻辑是研发驱动，不是政策驱动，你只要管线够厚，新药不断出来，它的成长是靠产品接力，而不是靠某一个政策、某一次采购活着。

所以你看创新药看上去波动大啊，也是事实，但它不容易被单一政策一棍子打死，所以相对呢也就更扛波动。从需求端来看，国内六零七零后的人口大部队也进入了老龄化，创新药的需求也会持续走高，叠加医保谈判以价换量，海外市场在打开增量空间，所以CXO的订单稳，ADC的高弹性也就形成了稳健加成长的双驱动，这也是机构长期看好这个指数的核心逻辑。那最后一部分，它适合哪部分人呢？一句话，它适合看好中国创新药出海和产业升级，不会选个股怕踩雷，同时能拿得住长期不追求一夜暴富的人。同样对于普通人来说，比较直接的参与就是通过公募基金。同样合规的原因，我肯定不会推荐某一支基金，但还是要提醒大家，创新药研发本身风险就比较高，临床实验也有可能失败，会直接影响公司估值，所以波动呢也相对较高。再加上医保谈判、集采都是行业常态，一定会带来阶段性的震荡。
